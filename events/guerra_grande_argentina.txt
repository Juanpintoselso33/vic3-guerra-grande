# EN: THE BIRTH OF THE THREE COUNTRIES OF THE ARGENTINE SIDE. All three are cut out of Argentina on
#     their historical dates by the relays in events/guerra_grande_argentina_calendar.txt.
#
#     THE RULES THIS FILE OBEYS, every one of them learned the hard way on the Uruguayan side:
#     - create_country CLONES the origin country's whole character roster, and the clone shares its
#       template with the original. So every character who must MOVE is saved into a scope BEFORE
#       the country is created; the new country is then EMPTIED of every clone without exception --
#       killed, not exiled, because vanilla's exile leaves the man alive as an agitator -- and only
#       then populated. The emptying lives in gg_argentina_new_country_people and its reasoning is
#       written there.
#     - c:<new tag> DOES resolve right after create_country, in the same effect: vanilla uses c:ZAN
#       immediately after creating it (events/zanzibar_events.txt:32). The rule that costs a day is
#       about change_tag, which is a different effect and a different problem. An earlier version of
#       this header said the opposite; it was wrong, and a wrong comment is worse than none.
#     - The country is created in IMMEDIATE, never inside an option. That is how vanilla does it, and
#       it is not a style choice: an option whose trigger asks about the new country cannot see it if
#       the option itself is what creates it. That is exactly how the seat-change options were born
#       unreachable.
#     - A ruler left unset is a ruler picked at random. Every one of the three is named explicitly.
#     - The seat change is offered as an option of the historical event itself, with
#       trigger = { is_player = yes }, the way vanilla does it in events/zanzibar_events.txt:150.
#       play_as goes LAST in the option: what happens to a popup open at that instant is not
#       verified, and nothing should depend on it.
# ES: EL NACIMIENTO DE LOS TRES PAISES DEL LADO ARGENTINO. Los tres se recortan de la Argentina en
#     sus fechas historicas, desde los relevos de events/guerra_grande_argentina_calendar.txt.
#
#     LAS REGLAS QUE CUMPLE ESTE ARCHIVO, todas aprendidas a los golpes del lado oriental:
#     - create_country CLONA el plantel entero de personajes del pais de origen, y el clon comparte
#       template con el original. Asi que todo personaje que tenga que MUDARSE se guarda en un scope
#       ANTES de crear el pais; despues el pais nuevo se VACIA de todos los clones sin excepcion --
#       matandolos, no exiliandolos, porque el exilio de vanilla lo deja vivo de agitador -- y recien
#       ahi se puebla. El vaciado vive en gg_argentina_new_country_people y el razonamiento esta
#       escrito ahi.
#     - c:<tag nuevo> SI resuelve justo despues de create_country, en el mismo efecto: vanilla usa
#       c:ZAN inmediatamente despues de crearlo. La regla que cuesta un dia es la de change_tag, que
#       es otro efecto y otro problema. Una version anterior de esta cabecera decia lo contrario:
#       estaba mal, y un comentario equivocado es peor que ninguno.
#     - El pais se crea en el IMMEDIATE, nunca adentro de una opcion. Asi lo hace vanilla, y no es
#       una cuestion de estilo: una opcion cuyo trigger pregunta por el pais nuevo no puede verlo si
#       es la propia opcion la que lo crea. Asi nacieron inalcanzables las opciones de mudanza.
#     - Un gobernante sin fijar es un gobernante al azar. Los tres se nombran explicitamente.
#     - El cambio de asiento se ofrece como opcion del evento historico mismo, con
#       trigger = { is_player = yes }, como lo hace vanilla en events/zanzibar_events.txt:150.
#       play_as va ULTIMO en la opcion: lo que le pasa a un popup abierto en ese instante no esta
#       verificado, y nada deberia depender de eso.
# -------------------------------------------------------------------------------------------------

# EN: gg_argentina.1 -- CORRIENTES SECEDES, 6 March 1839. It declares war on Rosas alone: no other
#     province follows it, and the reason it gives is the blockade on its commerce, not a doctrine.
#     Misiones goes with it: Corrientes had occupied the land south of the Aguapey since 1830, gave
#     it out in enfiteusis, and claimed the whole territory on 1 September 1832.
# ES: gg_argentina.1 -- CORRIENTES SE SEPARA, 6 de marzo de 1839. Le declara la guerra a Rosas sola:
#     ninguna otra provincia la sigue, y la razon que da es el bloqueo a su comercio, no una
#     doctrina. Misiones se va con ella: Corrientes ocupaba el territorio al sur del Aguapey desde
#     1830, lo repartio en enfiteusis y reivindico el territorio entero el 1/9/1832.
# SOURCE / FUENTE: docs/guerra-grande-argentina/historia-argentina.md y tabla-estados.md
# -------------------------------------------------------------------------------------------------
gg_argentina.1 = {
	type = country_event
	placement = ROOT

	title = gg_argentina.1.t
	desc = gg_argentina.1.d
	flavor = gg_argentina.1.f

	# ES: IMAGEN PROVISORIA, y queda dicho que lo es. La regla del mod es una imagen real de Wikimedia
	#     por evento, sin repetir, y pasarla a video Bink se hace en la torre. Hasta esa tanda, estos
	#     cuatro toman prestado un video de VANILLA -- no el de otro evento de la Guerra Grande, que
	#     romperia la regla de no repetir adentro del mod y pareceria una eleccion terminada. Anotado
	#     en PENDIENTES.md.
	event_image = {
		video = "gg_arg_corrientes"
	}

	icon = "gfx/interface/icons/event_icons/event_military.dds"

	duration = 12
	is_popup = yes

	trigger = {
		c:ARG ?= this
		NOT = { exists = c:CRR }
	}

	immediate = {
		debug_log = "GG_EV|[TimeKeeper.GetCurrentDate.GetString]|gg_argentina.1|" # GG_TRAZA
		hidden_effect = {
			# EN/ES: Ferre BEFORE the country exists. He has a vanilla template but is NOT created in
			#     the 1836 history -- his appearance depends on interest_group_leader_usage, on the
			#     rp1_content DLC and on a 1839-1867 window -- so he has to be found or made.
			#     / Ferre ANTES de que exista el pais. Tiene template de vanilla pero NO se crea en la
			#     historia de 1836, asi que hay que buscarlo o hacerlo.
			if = {
				limit = { any_scope_character = { has_template = ARG_pedro_ferre } }
				random_scope_character = {
					limit = { has_template = ARG_pedro_ferre }
					save_scope_as = gg_ferre
				}
			}
			else = {
				create_character = {
					template = ARG_pedro_ferre
					save_scope_as = gg_ferre
				}
			}
			# EN/ES: Corrientes se separa pase lo que pase: lo que eligen las opciones es la respuesta
			#     de Rosas, no si ocurre / Corrientes secedes either way
			gg_argentina_create_corrientes = yes
		}
		# EN/ES: 22/9/2026 (event audit, decided with Juan) -- the war opens with the secession, not with
		#     the answer: Pago Largo is scheduled by the calendar 25 days on and must never be fought
		#     without a war. Both options opened it anyway / la guerra se abre con la separacion, no con
		#     la respuesta: Pago Largo sale por calendario y nunca debe pelearse sin guerra
		gg_argentina_open_war = { TAG = CRR }
	}

	option = {
		debug_log = "GG_OPC|[TimeKeeper.GetCurrentDate.GetString]|gg_argentina.1.a|" # GG_TRAZA
		name = gg_argentina.1.a
		default_option = yes
		# EN/ES: Rosas contesta con el ejercito: Echague marcha (la guerra ya se abrio en immediate)
		#     / Rosas answers with the army (the war was already opened in immediate)
		ai_chance = { base = 85 }
	}

	option = {
		debug_log = "GG_OPC|[TimeKeeper.GetCurrentDate.GetString]|gg_argentina.1.b|" # GG_TRAZA
		name = gg_argentina.1.b
		# EN: the seat change, offered only to the player. Corrientes secedes either way: what this
		#     option decides is who you are from here on.
		# ES: el cambio de asiento, ofrecido solo al jugador. Corrientes se separa igual: lo que
		#     decide esta opcion es quien sos de aca en adelante.
		trigger = {
			is_player = yes
			c:CRR ?= { is_player = no }
		}
		ai_chance = { base = 0 }
		# EN/ES: last, always / ultimo, siempre
		custom_tooltip = gg_play_as_corrientes_tt
		hidden_effect = {
			c:CRR ?= { save_scope_as = gg_new_seat }
			play_as = scope:gg_new_seat
		}
	}
}

# EN: gg_argentina.20 -- THE RECKONING OF THE INTERIOR, 16 February 1843. The same day Oribe's army

#     Corrientes is one, the Coalition up to six with Cordoba. At most one ever out of hand means
#     Rosas never really had to fight for the interior; more than that, he spent it putting the
#     country back together. The bar itself is a photograph and gives both the same answer.
#     Hidden, because it is a reckoning and not news: the player already lived every one of these
#     battles.
# ES: gg_argentina.20 -- EL BALANCE DEL INTERIOR, 16 de febrero de 1843. El mismo dia que el ejercito
#     de Oribe llega frente a Montevideo en la otra orilla. Aca es donde el tandem se hace de verdad:
#     lee el tablero y escribe los dos estados compartidos, y desde aca el lado oriental puede
#     preguntar que fue del ejercito que tenia que cruzar.
#     QUE LEE. La barra no: la cuenta de provincias que se alzaron alguna vez, que no vuelve a bajar.
#     Corrientes es una, la Coalicion hasta seis con Cordoba. Como mucho una fuera de mano alguna vez
#     quiere decir que Rosas nunca tuvo que pelear de verdad por el interior; mas que eso, se lo paso
#     rearmando el pais. La barra sola es una foto y a los dos les da la misma respuesta.
#     Oculto, porque es un balance y no una noticia: el jugador vivio cada una de esas batallas.
# -------------------------------------------------------------------------------------------------
gg_argentina.20 = {
	type = country_event
	hidden = yes

	trigger = {
		c:ARG ?= this
	}

	immediate = {
		debug_log = "GG_EV|[TimeKeeper.GetCurrentDate.GetString]|gg_argentina.20|" # GG_TRAZA
		if = {
			# EN/ES: el interior sigue en armas: el ejercito no puede irse a otra guerra
			#     / the interior is still in arms: the army cannot leave for another war
			limit = {
				# EN: S18 -- in arms means independent of Buenos Aires, not merely alive: Corrientes
				#     brought back as a protectorate in 1839 still exists, and counting it blocked the
				#     crossing of 1843.
				# ES: S18 -- en armas quiere decir independiente de Buenos Aires, no solo vivo: la
				#     Corrientes devuelta como protectorado en 1839 sigue existiendo, y contarla bloqueaba
				#     el cruce de 1843.
				OR = {
					c:CRR ?= { OR = { NOT = { is_subject_of = c:ARG } has_war_with = c:ARG } }
					c:CLN ?= { OR = { NOT = { is_subject_of = c:ARG } has_war_with = c:ARG } }
				}
			}
			set_global_variable = { name = gg_interior_outcome value = 3 }
			set_global_variable = { name = gg_vanguardia_status value = 3 }
		}
		else_if = {
			# EN: HE WON, AND WHOLE -- and this now reads the count that never goes back down, not
			#     the bar. Until 20 September 2026 it asked for 144 points or more, which is a
			#     photograph of that morning: a Rosas who fought Corrientes and the Coalition for four
			#     years and annexed them both was back at 156 and got the same «clean» verdict as a
			#     Rosas nobody ever defied. What the tandem is trying to measure is what the interior
			#     COST, so it has to remember, and gg_provincias_alzadas is the memory: at most one
			#     province ever out of hand is a war Rosas never really had to fight.
			# ES: GANO, Y ENTERO -- y ahora esto lee la cuenta que no vuelve a bajar, no la barra.
			#     Hasta el 20/9/2026 pedia 144 puntos o mas, que es la foto de esa manana: un Rosas que
			#     peleo cuatro anios contra Corrientes y la Coalicion y las anexo a las dos estaba de
			#     vuelta en 156 y sacaba el mismo veredicto «limpio» que un Rosas al que nadie desafio.
			#     Lo que el tandem quiere medir es lo que COSTO el interior, asi que tiene que
			#     acordarse, y gg_provincias_alzadas es esa memoria: como mucho una provincia fuera de
			#     mano alguna vez es una guerra que Rosas nunca tuvo que pelear de verdad.
			limit = { global_var:gg_provincias_alzadas <= 1 }
			set_global_variable = { name = gg_interior_outcome value = 1 }
			set_global_variable = { name = gg_vanguardia_status value = 1 }
		}
		else = {
			# EN/ES: gano, pero le costo el interior entero / he won, but it cost him the interior
			set_global_variable = { name = gg_interior_outcome value = 2 }
			set_global_variable = { name = gg_vanguardia_status value = 2 }
		}
		# EN/ES: S18 -- the news comes in all three outcomes; held back, it says so
		#     / la noticia llega en los tres resultados; si la Vanguardia se queda, lo dice
		c:ARG ?= { trigger_event = { id = gg_argentina.21 days = 0 popup = yes } }
		hidden_effect = {
			if = {
				limit = { NOT = { has_global_variable = gg_arg_cal_done_8 } }
				set_global_variable = gg_arg_cal_done_8
			}
		}
	}
}
