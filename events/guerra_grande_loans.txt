# EN: The Guerra Grande was not paid for by the two governments that fought it. The Defensa
#     lived on French and then Brazilian money, and the Cerrito on the Confederation's, and
#     both pledged the only revenue either of them had -- the customs. This file gives that
#     money a price. Taking it is worth taking: cash now, cheaper war materiel, better troops.
#     Every instalment also pledges the customs, counts on a debt ledger, and is presented at
#     the peace. Refusing is a real option and it costs a real amount.
#
#     Nothing here makes a foreign power a belligerent. Brazil, France and the Confederation
#     appear only as money and paper, exactly as in events/guerra_grande_contingents.txt.
#
# ES: La Guerra Grande no la pagaron los dos gobiernos que la pelearon. La Defensa vivio de
#     plata francesa y despues brasilena, y el Cerrito de la de la Confederacion, y los dos
#     hipotecaron la unica renta que tenian: la aduana. Este archivo le pone precio a esa
#     plata. Tomarla vale la pena: caja ahora, material de guerra mas barato, mejor tropa.
#     Cada cuota tambien hipoteca la aduana, se anota en un libro de deuda y se cobra en la
#     paz. Negarse es una opcion de verdad y cuesta una cifra de verdad.
#
#     Nada de aca convierte a una potencia extranjera en beligerante. Brasil, Francia y la
#     Confederacion aparecen solo como plata y papel, igual que en
#     events/guerra_grande_contingents.txt.
#
# SOURCE / FUENTE: SOURCES_loans.md in ~/dev/juegos/victoria3-uruguay/. In short -- Talita Alves de
# Messias, "Irineu Evangelista de Souza na Guerra Grande", Historia Economica & Historia de
# Empresas 24:3 (2021); Paulo Roberto de Almeida, "A diplomacia financeira do Brasil no
# Imperio", on the Relatorio da Reparticao dos Negocios Estrangeiros of 1852; Claudia
# Contente, "La fiscalidad de la guerra permanente" (UPF, 2010); Nicolas Duffau and Ana
# Frega, "Definir, organizar y representar el territorio de la nacion" (2022); and the texts
# of the treaties of 12 October 1851 and of the conventions Arana-Southern and
# Arana-Le Predour.

# THE DEFENSA -- 12 June 1848
# =======================================================================================
# EN: The convention of prestacion de socorros with France was signed on 12 June 1848 and
#     came into force on the 15th, between the baron de Gros, vice-admiral Le Predour and the
#     charge d'affaires Devoize on one side and Joaquin Suarez's government on the other. It
#     established a reimbursable loan of 40,000 pesos corrientes at the end of every month,
#     "en dinero o en letras sobre Francia", from 30 June, to be repaid out of the customs
#     from 1852. Between June and December 1848 the Defensa drew 260,000 pesos in French
#     bills; in 1849 it drew the whole 480,000.
# ES: El convenio de prestacion de socorros con Francia se firmo el 12 de junio de 1848 y
#     entro en vigor el 15, entre el baron de Gros, el vicealmirante Le Predour y el
#     encargado de negocios Devoize por un lado y el gobierno de Joaquin Suarez por el otro.
#     Establecia un prestamo reembolsable de 40.000 pesos corrientes a fin de cada mes, "en
#     dinero o en letras sobre Francia", desde el 30 de junio, a pagarse con la aduana desde
#     1852. Entre junio y diciembre de 1848 la Defensa saco 260.000 pesos en letras
#     francesas; en 1849 saco los 480.000 enteros.
gg_loan.1 = {
	type = country_event
	placement = ROOT

	title = gg_loan.1.t
	desc = gg_loan.1.d
	flavor = gg_loan.1.f

	# EN: The French convention of 12 June 1848.
	event_image = {
		video = "gg_money_french_convention"
	}

	icon = "gfx/interface/icons/event_icons/event_trade.dds"

	# EN: 22/9/2026 -- duration is in MONTHS (save: utilitarian.4 duration = 3 -> expires 3 months on).
	#     The 1825 of 17/9 (152 years) left minimized events pending forever, and vanilla's 3 answers for
	#     the player within seconds at speed 5 (Juan, 17/9): 12 reopens it at 11 months, then resolves.
	# ES: la duracion va en MESES (en el save, 3 = vence a los 3 meses). El 1825 del 17/9 (152 anos)
	#     dejaba colgados para siempre los eventos minimizados, y el 3 de vanilla contesta por el jugador
	#     en segundos a velocidad 5: 12 lo reabre a los 11 meses y recien ahi resuelve.
	duration = 12

	trigger = {
		c:URU ?= this
		exists = c:CER
		NOT = { has_variable = gg_loan_settled }
	}

	option = {
		debug_log = "GG_OPC|[TimeKeeper.GetCurrentDate.GetString]|gg_loan.1.a|" # GG_TRAZA
		name = gg_loan.1.a
		custom_tooltip = gg_loan.1.a_tt2
		# EN/ES: T4 -- FE-2: signing keeps France in the Plata / firmar sostiene a Francia
		gg_patron_change = { PATRON = francia DELTA = 5 }
		set_global_variable = gg_french_convention
		default_option = yes
		add_treasury = 10000
		add_modifier = {
			name = guerra_grande_french_subsidy
			years = 5
			is_decaying = yes
		}
		# EN: one instalment on the ledger, and the customs pledged for it.
		# ES: una cuota en el libro, y la aduana hipotecada por ella.
		if = {
			limit = { NOT = { has_variable = gg_loan_debt } }
			set_variable = { name = gg_loan_debt value = 0 }
		}
		change_variable = {
			name = gg_loan_debt
			add = 1
		}
		add_modifier = {
			name = guerra_grande_customs_pledged
			years = 12
			is_decaying = yes
		}
		ai_chance = {
			base = 85
		}
	}

	option = {
		debug_log = "GG_OPC|[TimeKeeper.GetCurrentDate.GetString]|gg_loan.1.b|" # GG_TRAZA
		name = gg_loan.1.b
		# EN/ES: T4 -- FE-2: no convention, France pulls back / sin convenio, Francia se retira
		gg_patron_change = { PATRON = francia DELTA = -10 }
		add_modifier = {
			name = guerra_grande_defensa_self_reliance
			years = 5
			is_decaying = yes
		}
		ai_chance = {
			base = 15
		}
	}

	immediate = {
		debug_log = "GG_EV|[TimeKeeper.GetCurrentDate.GetString]|gg_loan.1|" # GG_TRAZA
		hidden_effect = {
			if = {
				limit = { NOT = { has_global_variable = gg_cal_done_20 } }
				set_global_variable = gg_cal_done_20
			}
		}
	}
}

# EN: The Cerrito's political bill, and Rosas' real aim. Elections were called in June 1845
#     and the Asamblea General was solemnly reinstalled on 11 August; its first resolutions
#     were to confirm Oribe as lawful president and to authorise the entry of foreign troops
#     in aid of his cause. In that same year Rosas proposed "reunifying the patria": the
#     reincorporation of Uruguay into the Provincias Unidas del Rio de la Plata, annulling the
#     Convencion Preliminar de Paz of 27 August 1828. Oribe would not decide and sent the
#     question to a parliamentary commission that resolved nothing.
#
#     Honesty about the record: some historians hold that Oribe and Rosas meant to annex the
#     Republic to the Confederation and others that no document supports it. What is not in
#     dispute is that the offer was made and that Oribe buried it in committee, and that by
#     article VI of the Arana-Southern convention of 24 November 1849 Rosas would only treat
#     with Britain if "su aliado el Exmo. senor Presidente de la Republica Oriental del
#     Uruguay, Brigadier D. Manuel Oribe, estuviese previamente conforme con ella" -- the
#     Cerrito's war was negotiated in Buenos Aires.
# ES: La factura politica del Cerrito, y el objetivo real de Rosas. Se convoco a elecciones en
#     junio de 1845 y la Asamblea General se reinstalo solemnemente el 11 de agosto; sus
#     primeras resoluciones fueron confirmar a Oribe como presidente legitimo y autorizar la
#     entrada de tropas extranjeras en auxilio de su causa. Ese mismo ano Rosas propuso
#     "reunificar la patria": la reincorporacion del Uruguay a las Provincias Unidas del Rio
#     de la Plata, anulando la Convencion Preliminar de Paz del 27 de agosto de 1828. Oribe no
#     quiso decidir y mando el tema a una comision parlamentaria que no resolvio nada.
#
#     Honestidad con la fuente: algunos historiadores sostienen que Oribe y Rosas pretendian
#     anexar la Republica a la Confederacion y otros que ningun documento lo respalda. Lo que
#     no se discute es que la propuesta se hizo y que Oribe la enterro en comision, y que por

#     Oriental del Uruguay, Brigadier D. Manuel Oribe, estuviese previamente conforme con
#     ella": la guerra del Cerrito se negociaba en Buenos Aires.
