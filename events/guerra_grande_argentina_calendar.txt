# -------------------------------------------------------------------------------------------------
# EN: THE DATED CALENDAR OF THE ARGENTINE SIDE. Nineteen relays carry the three preludes, the births
#     and the interior campaign to their delivery dates, counted in days from 1 January 1836.
#
#     WHY RELAYS AND NOT THE EVENTS THEMSELVES. A scheduled event's trigger is read WHEN IT IS
#     SCHEDULED, not on its future date. Scheduling the birth of Corrientes directly on day 1159
#     would test, on 1 January 1836, whether Corrientes does not yet exist and Argentina still holds
#     its states -- and would then fire on 6 March 1839 no matter what happened in between. So the
#     relay is unconditional, and every condition lives inside it, read on the day it matters. This
#     is the rule that cost the mod the partition calendar, Oribe's 1839 exit and three dated
#     events of the powers.
#
#     WHY ONLY ONE COPY. The Uruguayan calendar schedules two copies of every relay because the
#     Republic changes tag at the partition and can lose what is queued on it. These four are
#     scheduled on ARGENTINA, which never changes tag in this mod, so one copy is right and a second
#     would only be a second thing to keep in step.
#
#     THE MARK MEANS DELIVERED, NOT ATTEMPTED. Each gg_arg_cal_done_N is written INSIDE the same
#     limit that proves the recipient and its states exist. That is the correction of 19 September
#     2026: writing the mark first and looking for a recipient afterwards lost the event for the
#     whole game, in silence.
#
#     THE YEARS ARE 365 DAYS LONG, with no leap days -- the engine's years, not the calendar's. The
#     offsets were computed by hand and checked one by one.
# ES: EL CALENDARIO FECHADO DEL LADO ARGENTINO. Diecinueve relevos llevan las tres previas, los
#     nacimientos y la campania del interior a sus fechas de entrega, contadas desde el 1 de enero
#     de 1836.
#
#     POR QUE RELEVOS Y NO LOS EVENTOS DIRECTAMENTE. El trigger de un evento agendado se lee CUANDO
#     SE AGENDA, no en su fecha futura. Agendar el nacimiento de Corrientes directo al dia 1159
#     preguntaria, el 1 de enero de 1836, si Corrientes todavia no existe y si la Argentina conserva
#     sus estados -- y despues saldria el 6 de marzo de 1839 pasara lo que pasara en el medio. Por
#     eso el relevo va sin condiciones y toda condicion vive adentro, leida el dia que importa. Es la
#     regla que le costo al mod el calendario de la particion, la salida de Oribe en 1839 y tres
#     eventos fechados de las potencias.
#
#     POR QUE UNA SOLA COPIA. El calendario oriental agenda dos copias de cada relevo porque la
#     Republica cambia de tag en la particion y puede perder lo que tenga encolado. Estos cuatro se
#     agendan sobre la ARGENTINA, que en este mod no cambia de tag nunca, asi que una copia es lo
#     correcto y una segunda seria solo otra cosa que mantener sincronizada.
#
#     LA MARCA SIGNIFICA ENTREGADO, NO INTENTADO. Cada gg_arg_cal_done_N se escribe ADENTRO del mismo
#     limit que prueba que el destinatario y sus estados existen. Es la correccion del 19/9/2026:
#     escribir la marca primero y buscar destinatario despues perdia el evento toda la partida, en
#     silencio.
#
#     LOS ANIOS DEL MOTOR SON DE 365 DIAS, sin bisiestos. Los corrimientos se calcularon a
#     mano y se verificaron uno por uno.
# -------------------------------------------------------------------------------------------------

# -------------------------------------------------------------------------------------------------
# EN: «LA ARGENTINA» IS REQUIRED FOR THIS SIDE, and every relay checks it. Decision of 19 September
#     2026, after Codex's review caught it: of the eight Argentine states this side needs, only
#     STATE_CORRIENTES, STATE_TUCUMAN and STATE_JUJUY exist in vanilla (the count said two until
#     20 September 2026, when a second review checked it against the map files: Jujuy is there). Entre Rios, Cordoba, Salta, Misiones, La
#     Rioja and Catamarca are provinces that «la Argentina» adds -- vanilla does not split Argentina
#     into its historical provinces at all. The whole Argentine side was built reading the COMPATCH's
#     map, which has them, without checking that the standalone mod does not.
#     So rather than pretend, each relay asks for a state that only exists with «la Argentina»
#     loaded. Without it, the four relays do nothing, nothing is created, nothing breaks, and the
#     Uruguayan side plays exactly as it always did. The requirement is stated in README.md.
# ES: «LA ARGENTINA» ES REQUISITO DE ESTE LADO, y cada relevo lo chequea. Decision del 19/9/2026,
#     despues de que la revision de Codex lo agarrara: de los ocho estados argentinos que este lado
#     necesita, en vanilla existen solo STATE_CORRIENTES, STATE_TUCUMAN y STATE_JUJUY (la cuenta
#     decia dos hasta el 20/9/2026, cuando una segunda revision la chequeo contra los archivos del
#     mapa: Jujuy esta). Entre Rios, Cordoba, Salta,
#     Misiones, La Rioja y Catamarca son provincias que agrega «la Argentina» -- vanilla no parte a la
#     Argentina en sus provincias historicas. Todo este lado se armo leyendo el mapa del COMPATCH, que
#     si las tiene, sin chequear que el mod solo no.
#     Asi que en vez de disimular, cada relevo pide un estado que solo existe con «la Argentina»
#     cargada. Sin ella, los cuatro relevos no hacen nada, no se crea nada, no se rompe nada, y el
#     lado oriental se juega exactamente como siempre. El requisito esta dicho en README.md.
# -------------------------------------------------------------------------------------------------

# EN/ES: 6/3/1839 (dia 1159) -- Corrientes se separa y le declara la guerra a Rosas
gg_argentina_cal.1 = {
	type = country_event
	hidden = yes

	immediate = {
		hidden_effect = {
			if = {
				limit = {
					NOT = { has_global_variable = gg_arg_cal_done_1 }
					# EN/ES: guarda de «la Argentina»: Entre Rios no existe sin ella / the guard
					exists = s:STATE_ENTRE_RIOS
					exists = c:ARG
					NOT = { exists = c:CRR }
					exists = s:STATE_CORRIENTES.region_state:ARG
				}
				set_global_variable = gg_arg_cal_done_1
				if = {
					# EN: One refusal is enough to leave the old dispute alive. Only two concessions,
					#     and therefore an agravio count of zero, avert the secession.
					# ES: Una negativa alcanza para dejar vivo el pleito. Solo dos concesiones, y por
					#     eso una cuenta de agravio en cero, evitan la secesion.
					limit = {
						has_global_variable = gg_corrientes_agravio
						global_var:gg_corrientes_agravio = 0
					}
					c:ARG = { trigger_event = { id = gg_argentina.64 days = 0 popup = yes } }
				}
				else = {
					c:ARG = { trigger_event = { id = gg_argentina.1 days = 0 popup = yes } }
				}
			}
		}
	}
}

# EN/ES: 1/2/1852 (dia 5871) -- renuncia Pacheco
gg_argentina_cal.9 = {
	type = country_event
	hidden = yes

	immediate = {
		hidden_effect = {
			if = {
				limit = {
					NOT = { has_global_variable = gg_arg_cal_done_9 }
					exists = s:STATE_ENTRE_RIOS
					exists = c:ARG
					# EN: only if there is a war to lose. The comment said this and the code did not:
					#     it asked whether Entre Rios EXISTED, which is a different question. A 1851
					#     war that ended in a status quo left Entre Rios standing and at peace, and
					#     on 1 February 1852 Pacheco still resigned and on the third «the hour of
					#     Caseros» still arrived, announcing an Ejercito Grande a few leagues off
					#     that was not marching anywhere. Corrected 20/9/2026 (Codex).
					# ES: solo si hay una guerra que perder. El comentario lo decia y el codigo no: lo
					#     que preguntaba era si Entre Rios EXISTIA, que es otra pregunta. Una guerra
					#     de 1851 terminada en statu quo dejaba a Entre Rios en pie y en paz, y el 1
					#     de febrero de 1852 Pacheco renunciaba igual y el 3 llegaba igual «la hora de
					#     Caseros», anunciando un Ejercito Grande a unas leguas que no marchaba a
					#     ningun lado. Corregido el 20/9/2026 (Codex).
					exists = c:ENR
					c:ARG = { has_war_with = c:ENR }
				}
				set_global_variable = gg_arg_cal_done_9
				c:ARG = { trigger_event = { id = gg_argentina.40 days = 0 popup = yes } }
			}
		}
	}
}
