# EN: THE ARGENTINE SIDE HAS ITS OWN NAMESPACE, and it has it because of what happened on 20/9/2026.
#     The opening of the Federal Pact was written as gg_intro.5 -- a number that was already taken by
#     the event that opens the Cerrito's war. Two events with the same id: the engine keeps one and
#     the other simply is not there. So Argentina never got an opening event at all, and Juan spent
#     an afternoon telling me the journal did not appear while I looked for the cause in the schedule.
#     He put it plainly: this will keep happening as long as the two sides share numbering.
#     From here the Argentine side files its own events under gg_arg_intro, and validate_mod.py fails
#     on any duplicated event id anywhere in the mod, which is a check that should have existed since
#     the first day.
# ES: EL LADO ARGENTINO TIENE NAMESPACE PROPIO, y lo tiene por lo que paso el 20/9/2026. La apertura
#     del Pacto Federal se escribio como gg_intro.5 -- un numero que ya estaba ocupado por el evento
#     que abre la guerra del Cerrito. Dos eventos con el mismo id: el motor se queda con uno y el otro
#     sencillamente no esta. Asi que la Argentina nunca tuvo evento de apertura, y Juan se paso una
#     tarde diciendome que el journal no aparecia mientras yo buscaba la causa en el agendado.
#     Lo dijo sin vueltas: esto va a seguir pasando mientras los dos lados compartan numeracion.
#     De aca en adelante el lado argentino archiva sus eventos bajo gg_arg_intro, y validate_mod.py
#     falla ante cualquier id de evento repetido en todo el mod, que es un chequeo que tendria que
#     haber existido desde el primer dia.
# -------------------------------------------------------------------------------------------------


# -------------------------------------------------------------------------------------------------
# EN: gg_arg_intro.1 -- THE OPENING OF THE ARGENTINE SIDE, day one. Written 20/9/2026 because Juan sat
#     down to play Argentina and found the Federal Pact already pinned on his screen with nobody
#     having said what it was, and then three years of silence until Corrientes secedes in March
#     1839. The mod's own rule, recorded in decisiones.md, is that EVERY journal is opened by an
#     event that explains it -- the Uruguayan side has had that since the first day and this one
#     never got its own.
#     So the entry is no longer handed out by the on_action: it is opened here, by the government
#     that holds it, which is also the only way the player learns what the count means before it
#     starts moving.
#     WHY IT SAYS WHAT COMES NEXT. Three years is a long time to sit in front of a number that does
#     nothing. The last paragraph names the two things that can move it -- a legislature withdrawing
#     the charge, and the army in front of Montevideo -- so the wait is a wait for something.
# ES: gg_arg_intro.1 -- LA APERTURA DEL LADO ARGENTINO, primer dia. Escrito el 20/9/2026 porque Juan se
#     sento a jugar la Argentina y se encontro el Pacto Federal ya fijado en pantalla sin que nadie
#     le dijera que era, y despues tres anios de silencio hasta que Corrientes se separa en marzo de
#     1839. La regla del propio mod, anotada en decisiones.md, es que a CADA journal lo abre un
#     evento que lo explica -- el lado oriental lo tiene desde el primer dia y a este nunca le toco.
#     Asi que la entrada ya no la reparte el on_action: la abre aca el gobierno que la tiene, que es
#     ademas la unica manera de que el jugador entienda que cuenta ese numero antes de que empiece a
#     moverse.
#     POR QUE DICE LO QUE VIENE. Tres anios es mucho tiempo para mirar un numero que no hace nada. El
#     ultimo parrafo nombra las dos cosas que lo pueden mover -- una legislatura que retira el
#     encargo, y el ejercito frente a Montevideo -- asi que la espera es espera de algo.
# SOURCE / FUENTE: Pacto Federal del 4 de enero de 1831, tratado entre entidades soberanas; la
#     delegacion de las relaciones exteriores y el derecho de cada provincia a retirarla. El detalle
#     esta en docs/guerra-grande-argentina/historia-argentina.md.
# -------------------------------------------------------------------------------------------------
gg_arg_intro.1 = {
	immediate = { debug_log = "GG_EV|[TimeKeeper.GetCurrentDate.GetString]|gg_arg_intro.1|" } # GG_TRAZA
	type = country_event
	placement = ROOT

	title = gg_arg_intro.1.t
	desc = gg_arg_intro.1.d
	flavor = gg_arg_intro.1.f

	# EN/ES: IMAGEN PROVISORIA, como las cuatro del lado argentino y por la misma razon: falta la
	#     tanda de imagenes propias. Anotado en PENDIENTES.md / provisional image, as noted
	event_image = {
		video = "gg_arg_rosas_1833"
	}

	icon = "gfx/interface/icons/event_icons/event_scales.dds"

	duration = 12
	is_popup = yes

	trigger = {
		# EN/ES: se dispara sobre la Argentina y nada mas, asi que se pregunta por el pais y no por una
		#     variable: una marca que todavia no este puesta descarta el evento en silencio
		#     / it is fired on Argentina and nowhere else, so ask for the country, not for a mark
		c:ARG ?= this
		NOT = { has_journal_entry = je_gg_delegation }
		# EN/ES: la sonda de «la Argentina»: sin ella este lado no existe / the «la Argentina» probe
		exists = s:STATE_ENTRE_RIOS
	}

	option = {
		debug_log = "GG_OPC|[TimeKeeper.GetCurrentDate.GetString]|gg_arg_intro.1.a|" # GG_TRAZA
		name = gg_arg_intro.1.a
		default_option = yes
		add_contextless_journal_entry = je_gg_delegation
		ai_chance = { base = 100 }
	}
}


# -------------------------------------------------------------------------------------------------
# EN: gg_arg_intro.2 -- THE SAFETY NET, hidden, forty days in. Written 20/9/2026 because the entry did
#     not open in Juan's game and the whole Argentine side hangs off it: without the Pacto Federal
#     there is no bar of provinces, no reading of the interior and no ending for Rosas.
#     It is deliberately dumb: if Argentina still has no entry and «la Argentina» is loaded, it opens
#     it without a word. The explanation is gg_arg_intro.1's job; this one only makes sure the thing
#     exists. A silent open is worse than an explained one and far better than none.
# ES: gg_arg_intro.2 -- LA RED, oculta, a los cuarenta dias. Escrita el 20/9/2026 porque la entrada no se
#     abrio en la partida de Juan y de ella cuelga el lado argentino entero: sin el Pacto Federal no
#     hay cuenta de provincias, ni lectura del interior, ni final para Rosas.
#     Es deliberadamente tonta: si la Argentina sigue sin la entrada y «la Argentina» esta cargada, la
#     abre sin decir nada. Explicar es trabajo de gg_arg_intro.1; esta solo se asegura de que exista. Una
#     apertura muda es peor que una explicada y muchisimo mejor que ninguna.
# -------------------------------------------------------------------------------------------------
gg_arg_intro.2 = {
	type = country_event
	hidden = yes

	immediate = {
		debug_log = "GG_EV|[TimeKeeper.GetCurrentDate.GetString]|gg_arg_intro.2|" # GG_TRAZA
		hidden_effect = {
			if = {
				limit = {
					c:ARG ?= this
					NOT = { has_journal_entry = je_gg_delegation }
					exists = s:STATE_ENTRE_RIOS
				}
				add_contextless_journal_entry = je_gg_delegation
			}
		}
	}
}
