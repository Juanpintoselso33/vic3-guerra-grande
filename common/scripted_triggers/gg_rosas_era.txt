# EN: Rosas's era is over once the war of the Federal Pact has an outcome that takes the government
#     from him: Urquiza's victory, the constitutional settlement, or the collapse of the mandate. A
#     negotiated stalemate or Rosas's own victory keeps him in power, so the vote stays shut.
# ES: la era de Rosas termina cuando la guerra del Pacto tiene un desenlace que le quita el gobierno:
#     la victoria de Urquiza, el arreglo constitucional o el derrumbe del mandato. Un empate negociado o
#     la victoria de Rosas lo dejan en el poder, y el voto sigue cerrado.
gg_x_arg_rosas_era_over = {
	OR = {
		has_global_variable = gg_pact_settlement_urquiza
		# EN: 25/9/2026 (Juan, AUD-ROSAS-SUMA) -- the negotiated confederation ends the era only if a constitution follows:
		#     with «the Pact without a Constitution» (gg_constitution.1.b, gg_constitution_chosen = 2) Rosas keeps the sum
		#     of public power until his death (gg_rosas_holds_the_sum_of_power, below).
		# ES: la confederacion negociada termina la era solo si le sigue una constitucion: con «el Pacto sin Constitucion»
		#     Rosas conserva la suma del poder publico hasta su muerte.
		AND = {
			has_global_variable = gg_pact_settlement_constitutional
			NOT = { global_var:gg_constitution_chosen ?= 2 }
		}
		has_global_variable = gg_pact_settlement_mandate_collapsed
		# EN: 23/9/2026 (audit X5) -- a constitution also ends the era: the Constitution of 1853 chosen after the
		#     Pact (gg_constitution.1.a sets 1; 2 is "the Pact without a constitution", which keeps Rosas's regime),
		#     or the constitution written after Rosas's death by the winner of federales against unitarios
		#     (gg_constitution.3, outcome 1 federal or 2 unitary).
		# ES: una constitucion tambien termina la era: la de 1853 elegida tras el Pacto (2 = sin constitucion, sigue
		#     el regimen de Rosas), o la que escribe el ganador tras la muerte de Rosas.
		global_var:gg_constitution_chosen ?= 1
		# EN/ES: 24/9/2026 (AUD-CONST-CHOICE) -- 3, the constitution of the State of Buenos Aires (gg_constitution.1.e),
		#     ends it too: a written law with a vote / 3, la constitucion del Estado, tambien: una ley escrita con voto
		global_var:gg_constitution_chosen ?= 3
		has_global_variable = gg_constitution_outcome
		# EN: 23/9/2026 (Juan) -- the reunion of Buenos Aires after Pavon also ends it: gg_ba_done is set when the
		#     State of Buenos Aires and the Confederation become one country again (guerra_grande, gg_ba.20).
		# ES: la reunion de Buenos Aires despues de Pavon tambien la termina: gg_ba_done se prende cuando el Estado
		#     de Buenos Aires y la Confederacion vuelven a ser un pais (gg_ba.20).
		has_global_variable = gg_ba_done
	}
}

# EN: 25/9/2026 (Juan's decision, AUD-ROSAS-SUMA; his USA game on 0.1.6) -- «the Pact without a Constitution»
#     (gg_constitution.1.b) leaves Rosas with «la suma del poder publico» (law of the Sala, 7 March 1835) until he dies,
#     whatever settlement came before, except the two that took the government from him (Urquiza's victory, which does
#     not offer .1.b, and the fallen mandate, which seats Urquiza). In Juan's game the AI chose .1.b on 1/4/1852 after the
#     negotiated confederation, the script read the era as over, and an engine coup seated Angel Pacheco on 4/10/1854.
#     Ends with his death (gg_rosas_succession_monthly opens gg_constitution.2) or a later constitution. Read by the seat
#     keeper (gg_rosas_keeps_the_seat) and by the guard that shuts coups and revolutions (gg_arg_identity_guard).
# ES: «el Pacto sin Constitucion» deja a Rosas con la suma del poder publico hasta su muerte, sea cual sea el cierre
#     previo, salvo los dos que le quitaron el gobierno. En la partida de Juan la IA eligio .1.b el 1/4/1852 tras la
#     confederacion negociada, el script dio la era por terminada y un golpe del motor sento a Angel Pacheco el 4/10/1854.
gg_rosas_holds_the_sum_of_power = {
	global_var:gg_constitution_chosen ?= 2
	NOT = { has_global_variable = gg_pact_settlement_urquiza }
	NOT = { has_global_variable = gg_pact_settlement_mandate_collapsed }
	NOT = { has_global_variable = gg_rosas_succession_crisis }
	NOT = { has_global_variable = gg_constitution_outcome }
	NOT = { has_global_variable = gg_ba_done }
	any_country = { any_scope_character = { has_template = ARG_Juan_Manuel_de_Rosas is_character_alive = yes } }
}

# EN: 25/9/2026 (Juan: «if Rosas stays dictator until his death, having won, the flag is the Confederation's and it is
#     still called Confederacion Argentina») -- Rosas's Argentine Confederation still stands: Rosas is alive and in
#     Argentina, and either he holds the sum of public power («the Pact without a Constitution», above) or his era has
#     not ended (gg_x_arg_rosas_era_over: no Urquiza victory, no fallen mandate, no constitution, no reunion after Pavon;
#     his victory in the Pact war, gg_pact_settlement_rosas, keeps it). Left out: the two governments of a drawn Pact
#     war (gg_pact_settlement_stalemate), where the Confederation is Urquiza's and Rosas keeps only Buenos Aires, and the
#     succession crisis. Read by ARG's flag (common/flag_definitions/zzzzz_gg_rosas_confederation_flag.txt) and name
#     (common/dynamic_country_names/zz_guerra_grande_country_names.txt). When Rosas dies, goes into exile or a
#     constitution replaces his regime, it stops being true and the normal selection of the playset comes back.
# ES: la Confederacion Argentina de Rosas sigue en pie: Rosas vivo y en la Argentina, y o tiene la suma del poder publico
#     o su era no termino (su victoria en la guerra del Pacto la mantiene). Afuera: los dos gobiernos de unas tablas (la
#     Confederacion es la de Urquiza) y la crisis de sucesion. Lo leen la bandera y el nombre de ARG. Cuando Rosas muere,
#     se exilia o una constitucion reemplaza su regimen, deja de valer y vuelve la seleccion normal del playset.
gg_rosas_confederation_endures = {
	c:ARG ?= { any_scope_character = { has_template = ARG_Juan_Manuel_de_Rosas is_character_alive = yes } }
	OR = {
		gg_rosas_holds_the_sum_of_power = yes
		AND = {
			NOT = { gg_x_arg_rosas_era_over = yes }
			NOT = { has_global_variable = gg_pact_settlement_stalemate }
			NOT = { has_global_variable = gg_rosas_succession_crisis }
		}
	}
}
