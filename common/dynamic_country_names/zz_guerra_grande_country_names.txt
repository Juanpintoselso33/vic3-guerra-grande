# EN: THE ORIENTAL PROVINCE (hotfix 0.1.1, 24/9/2026, Juan). While the Republic is a province of the Pact
#     under Buenos Aires (gg_oriental_make_province: gg_oriental_province set, subject of Argentina), the
#     country is called «Provincia Oriental», the name the Sala de Representantes used in the Law of Union
#     of 25 August 1825 («Queda la Provincia Oriental del Rio de la Plata unida a las demas de este nombre»).
#     «Banda Oriental» names the region, not the province. The same trigger as its Treinta y Tres flag
#     (common/flag_definitions/zz_guerra_grande_flags.txt), so name and flag change together and both
#     go back to «Uruguay» the moment it stops being Buenos Aires's subject: nothing to undo.
#     INJECT, not REPLACE: vanilla's and Dynamic Names, Flags & Colours's names for URU stay; this file
#     sorts after both (00_dynamic_country_names.txt, dnfc_brazil_country_names.txt), as the flag file
#     sorts after DNFC's and wins in Juan's playset. INJECT on dynamic names is how the British Flavour
#     Pack (Workshop 3713104798, INJECT:GBR) adds its own. Priority above DNFC's «dyn_c_URU_subject» (1).
# ES: LA PROVINCIA ORIENTAL. Mientras la Republica sea provincia del Pacto bajo Buenos Aires, el pais se
#     llama «Provincia Oriental», el nombre de la Ley de Union del 25 de agosto de 1825. «Banda Oriental»
#     es la region. El mismo trigger que su bandera de los Treinta y Tres: nombre y bandera cambian juntos
#     y vuelven a «Uruguay» apenas deja de ser sujeta de Buenos Aires. INJECT: se conservan los nombres
#     de vanilla y de DNFC.
# SOURCE / FUENTE: Ley de Union, Sala de Representantes de la Provincia Oriental, Florida, 25/8/1825
#     (text: https://es.wikisource.org/wiki/Declaraci%C3%B3n_de_Independencia_de_Uruguay ; Uruguay Educa/ANEP,
#     https://uruguayeduca.anep.edu.uy/efemerides/declaratoria-de-la-independencia ; printed in Armand Ugon et
#     al., Compilacion de leyes y decretos 1825-1930, t. 1, pp. 84-89).
# -------------------------------------------------------------------------------------------------
INJECT:URU = {
	dynamic_country_name = {
		name = gg_dyn_provincia_oriental
		adjective = gg_dyn_provincia_oriental_adj

		is_main_tag_only = yes
		priority = 150

		trigger = {
			exists = c:ARG
			has_global_variable = gg_oriental_province
			scope:actor ?= { is_subject_of = c:ARG }
		}
	}
	# EN: 25/9/2026 (AUD-CIS-PUPPET; Juan, Brazil's AI took Uruguay after 1854: «it is not the Cisplatina, it is
	#     "Brazilian Uruguay"»). While the country is the Cisplatine Province of the Empire (the subject type, reached by
	#     the peace, gg_peace.1.h, or by any engine route through gg_cisplatina_convert), it is called «Provincia
	#     Cisplatina». Needed with Dynamic Names, Flags & Colours: its REPLACE_OR_CREATE:URU drops vanilla's
	#     dyn_c_cisplatina and names a Brazilian puppet «Brazilian Uruguay» (dyn_c_URU_subject, priority 1,
	#     use_overlord_prefix); More Dynamic Names And Flags injects the Cisplatina back, but at priority 0, so it loses.
	#     Same trigger as the Cisplatina flag (zz_guerra_grande_flags.txt): name and flag go back together on release.
	# ES: mientras sea la Provincia Cisplatina del Imperio (el tipo de sujecion, por la paz o por cualquier camino del
	#     motor), se llama «Provincia Cisplatina». Hace falta con DNFC, que reemplaza el bloque URU de vanilla (y su
	#     dyn_c_cisplatina) y llama «Brazilian Uruguay» al titere del Brasil. Mismo trigger que la bandera cisplatina.
	dynamic_country_name = {
		name = gg_dyn_provincia_cisplatina
		adjective = gg_dyn_provincia_cisplatina_adj

		is_main_tag_only = yes
		priority = 150

		trigger = {
			exists = c:BRZ
			scope:actor ?= {
				is_subject_of = c:BRZ
				is_subject_type = subject_type_gg_cisplatine_province
			}
		}
	}
}

# EN: 25/9/2026 (Juan: «... and it is still called Confederacion Argentina») -- while Rosas's Confederation stands
#     (gg_rosas_confederation_endures, the same trigger as its flag in zzzzz_gg_rosas_confederation_flag.txt), Argentina
#     is «Confederacion Argentina» / «Argentine Confederation», whatever its laws. What it overrides (checked 25/9/2026):
#     vanilla's dyn_c_argentine_confederation needs a dictatorship and Rosas as ruler (priority 0); Dynamic Names, Flags &
#     Colours (dnfc_la_plata_country_names.txt, REPLACE_OR_CREATE:ARG) names it by laws -- a presidential republic with a
#     vote is «Argentina»; More Dynamic Names And Flags (z_more_dynamic_names.txt, INJECT_OR_CREATE:ARG) has «Buenos
#     Aires» for a small Rosas country and «Argentine Empire» or «People's Republic» up to priority 20; vanilla's
#     «Argentina Legionaria» is 30. la Argentina defines no ARG name. This file sorts after all of them and nothing later
#     touches ARG, so an INJECT at priority 1000 wins. Its own key, not vanilla's, so no mod's localization can move it.
# ES: mientras siga la Confederacion de Rosas (el mismo trigger que su bandera), la Argentina se llama «Confederacion
#     Argentina», tenga las leyes que tenga: le gana a vanilla (dictadura con Rosas, prioridad 0), a DNFC (por leyes: una
#     republica presidencial con voto es «Argentina»), a More Dynamic Names («Buenos Aires», «Imperio», hasta 20) y a la
#     «Argentina Legionaria» de vanilla (30). Clave propia, para que ninguna localizacion de otro mod la cambie.
# -------------------------------------------------------------------------------------------------
INJECT:ARG = {
	dynamic_country_name = {
		name = gg_dyn_confederacion_argentina
		adjective = ARG_ADJ

		is_main_tag_only = yes
		priority = 1000

		trigger = {
			gg_rosas_confederation_endures = yes
		}
	}
}
