# EN: 25/9/2026 (AUD-DUP-ECCHI, Juan's decision: option a) -- «Expanded Characters & Commanders of Historical Importance
#     Redux» (Workshop 3261096208, ECCHI) brings its own templates of historical figures that the game already has (vanilla,
#     la Argentina or this mod): in Juan's Argentina game two Bernardo Berros sat in the Oriental Province in 1853 and a
#     second Sarmiento in Argentina from 1862. Ours stays (face, biography, historical life). Each ECCHI duplicate below is
#     redefined WITHOUT its usage blocks (interest_group_leader_usage / commander_usage / ...), so the engine never picks
#     it, and without its dna (so the copy is harmless when ECCHI is not loaded). ECCHI has no history nor events: its
#     templates only ever appear through those usage blocks. REPLACE_OR_CREATE because ECCHI loads before this mod and
#     defines them the same way; without ECCHI they are unused templates.
#     The list: every ECCHI template with the same birth date and surname as a vanilla, la Argentina or Guerra Grande
#     template (tools/ecchi_duplicates.py in the design repo regenerates it), plus Artigas, who never returned from
#     Paraguay and whose letter the mod tells (gg_artigas_letter).
# ES: el mod ECCHI trae sus propias plantillas de figuras que el juego ya tiene: dos Berro en la Provincia Oriental de 1853
#     y un segundo Sarmiento desde 1862. Queda la nuestra. Cada duplicado se redefine SIN sus bloques de uso (el motor
#     nunca lo elige) y sin ADN (inofensivo si ECCHI no esta cargado). Mas Artigas, que nunca volvio del Paraguay.
