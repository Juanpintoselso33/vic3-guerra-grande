# EN: THE DEFENSA'S FLAG IS A WARTIME FLAG, NOT URUGUAY'S FLAG.
#     Playtest 2026-09-19: "when the war ends Uruguay is left with the Defensa's flag, it has to go
#     back to normal". It did not go back because the Defensa's coat of arms was keyed URU in
#     common/coat_of_arms/, which overrides Uruguay's arms for the entire game -- there is no end
#     date on a coat of arms. Worse in the other branch: a Cerrito that won the war and took the URU
#     tag ended up flying the flag of the government it had just beaten.
#     A flag_definition is the right tool: it carries a trigger, so the flag is conditional and the
#     vanilla arms stay untouched underneath. Two conditions, both needed:
#       - the country is actually the Defensa government (the Cerrito never gets this flag), and
#       - the war is still open (gg_peace_settled is the marker every ending sets, including the
#         one the closing dispatch writes when a third country takes the war away from both).
#     When either stops being true the definition stops applying and vanilla's URU flag returns, in
#     the same frame, with no effect to call and nothing to remember to undo.
# ES: LA BANDERA DE LA DEFENSA ES UNA BANDERA DE GUERRA, NO LA DEL URUGUAY.
#     Prueba en partida 19/9/2026: "cuando termina la guerra Uruguay queda con la bandera de la
#     Defensa, tiene que volver a lo normal". No volvia porque el escudo de la Defensa estaba con la
#     clave URU en common/coat_of_arms/, que le pisa el escudo al Uruguay toda la partida: un escudo
#     no tiene fecha de vencimiento. Peor en la otra rama: un Cerrito que ganaba la guerra y tomaba
#     el tag URU terminaba con la bandera del gobierno que acababa de derrotar.
#     Un flag_definition es la herramienta correcta: lleva trigger, asi que la bandera es
#     condicional y el escudo de vanilla queda intacto abajo. Dos condiciones, las dos necesarias:
#       - que el pais sea de verdad el gobierno de la Defensa (el Cerrito nunca lleva esta bandera), y
#       - que la guerra siga abierta (gg_peace_settled es la marca que prende todo final, incluido
#         el que escribe el despacho de cierre cuando un tercero les saca la guerra a los dos).
#     Cuando cualquiera de las dos deja de ser cierta, la definicion deja de aplicar y vuelve la
#     bandera de vanilla, en el mismo cuadro, sin ningun efecto que llamar ni nada que acordarse de
#     deshacer.
#
#     SOURCE / FUENTE: "Flag of Uruguay (Rivera).svg", el archivo que ilustra el articulo "Gobierno
#     de la Defensa" de Wikipedia con el epigrafe "Bandera de Uruguay usada por el Gobierno de la
#     Defensa". La imagen bajada y convertida, no redibujada.
# -------------------------------------------------------------------------------------------------

# EN: 22/9/2026 -- REPLACE, not a plain block. Vanilla already defines URU, and a second "URU = {"
#     is dropped at load ("Duplicated key URU will not be created"), so the Defensa's flag never
#     applied. REPLACE carries vanilla's definitions unchanged (00_flag_definitions.txt, 1.13) plus ours.
# ES: REPLACE, no un bloque comun. Vanilla ya define URU y un segundo "URU = {" se descarta al cargar,
#     asi que la bandera de la Defensa nunca se aplicaba. REPLACE lleva las definiciones de vanilla sin
#     cambios mas la nuestra.
# EN/ES: vanilla's canton scale, used by its URU block below / la escala del canton de vanilla
@third = @[1/3]

REPLACE:URU = {
	# EN/ES: 23/9/2026 (Juan) -- the Pact province flies the Treinta y Tres flag; a republic apart under
	#     Buenos Aires keeps the Uruguayan flag; under the Empire, the Cisplatina's / la provincia del Pacto
	#     lleva la de los Treinta y Tres; la republica aparte, la uruguaya de siempre; bajo el Imperio, la Cisplatina
	flag_definition = {
		coa = gg_provincia_oriental
		priority = 150
		trigger = { exists = c:ARG has_global_variable = gg_oriental_province scope:actor ?= { is_subject_of = c:ARG } }
	}
	flag_definition = {
		coa = gg_cisplatina
		priority = 150
		trigger = { exists = c:BRZ scope:actor ?= { is_subject_of = c:BRZ } }
	}
	flag_definition = {
		coa = gg_defensa_government
		priority = 100
		trigger = {
			scope:actor ?= {
				has_variable = guerra_grande_defensa_government
				NOT = { has_global_variable = gg_peace_settled }
			}
		}
	}
	# EN/ES: vanilla 1.13, unchanged / sin cambios
	flag_definition = {
		coa = URU
		subject_canton = URU
		allow_overlord_canton = yes
		coa_with_overlord_canton = URU_subject
		overlord_canton_scale = { @third 0.557 }
		priority = 1
	}
	flag_definition = {
		coa = URU_monarchy
		subject_canton = URU_monarchy
		priority = 5
		trigger = {
			coa_def_monarchy_flag_trigger = yes
		}
	}
	flag_definition = {
		coa = URU_absolute_monarchy
		subject_canton = URU_absolute_monarchy
		priority = 20
		trigger = {
			coa_def_absolute_monarchy_flag_trigger = yes
		}
	}
	flag_definition = {
		coa = URU_dictatorship
		subject_canton = URU_dictatorship
		priority = 20
		trigger = {
			coa_def_dictatorship_flag_trigger = yes
		}
	}
	flag_definition = {
		coa = URU_communist
		priority = 1500
		trigger = {
			coa_def_communist_flag_trigger = yes
		}
	}
	flag_definition = {
		coa = URU_subject_SPA
		priority = 50
		trigger = {
			coa_def_spanish_ensign_trigger = yes
		}
	}
	flag_definition = {
		coa = URU_subject_BRZ
		priority = 50
		trigger = {
			OR = {
				coa_def_brazilian_ensign_trigger = yes
				AND = {
					exists = c:POR
					scope:actor ?= {
						is_subject_of = c:POR
					}
				}
			}
		}
	}
	flag_definition = {
		coa = URU_subject_USA
		priority = 50
		trigger = {
			coa_def_american_ensign_trigger = yes
		}
	}
}

# EN: THE ELEVEN PROVINCES AS COUNTRIES: WHICH FLAG, WHEN. Decided by Juan on 22/9/2026: «the
#     proposals, historically, and afterwards, if they are alive when historical flags appear, we use
#     those» (docs/guerra-grande-argentina/banderas-provincias-opciones.md). The coats of arms are in
#     common/coat_of_arms/coat_of_arms/zz_guerra_grande_argentina.txt. Priorities, lowest to highest:
#       1  the period flag, keyed on the tag: the Confederation's dark blue for nine of them, Cordoba's
#          and Santa Fe's own tricolours for the other two.
#       10 once the period flag is gone, the national celeste and white: the dark blue was Rosas's and
#          ends at Caseros (3/2/1852, the same cut the playset's ARG flags use in
#          la-argentina-compatches/tools/build_dnfc_compatch.py); Cordoba's tricolour «must have been
#          abandoned before March 1854» (Prando 2009); Santa Fe's was abandoned in 1880 (Wikipedia ES,
#          «Bandera de la provincia de Santa Fe»).
#       20 Tucuman, Salta, Jujuy, Catamarca and La Rioja only: the celeste while the Coalition of the
#          North stands and the province is on its side -- not under anyone. «Tucuman changed flag
#          when it changed side» (the doc). Beaten provinces are born as provinces of the Pact under
#          Buenos Aires (gg_province_split_off), so under the Pact they keep the federal flag.
#       30 and 31 the provincial flag of today, from the date of the law that adopted it.
#       40 while the confederation stands (gg_confederation_stands), the province's FIRST provincial flag,
#          whatever its date (Juan, 24/9/2026, AUD-FLAG-CONFED; a deliberate anachronism). Same rule for the nine
#          territories made provinces and for Corrientes and Entre Rios, at the end of this file.
#     No other mod in the playset defines these eleven tags in flag_definitions (checked 22/9/2026
#     against every downloaded Workshop item, DNFC's REPLACE_OR_CREATE lists included), so a plain
#     block is not dropped at load. The DEFAULT list's communist (1000) and anarchist (2000) flags
#     still win above these, as for any country.
# ES: LAS ONCE PROVINCIAS COMO PAISES: QUE BANDERA, CUANDO. Decidido por Juan el 22/9/2026: «las
#     propuestas historicamente y despues, si estan vivos cuando aparecen banderas historicas, usamos
#     esas». Prioridades, de menor a mayor:
#       1  la bandera del periodo, con la clave del tag: el azul oscuro de la Confederacion para nueve,
#          las tricolores propias de Cordoba y Santa Fe para las otras dos.
#       10 cuando se acaba la del periodo, la celeste y blanca nacional: el azul oscuro era de Rosas y
#          termina en Caseros (3/2/1852, el mismo corte que usan las banderas de ARG del playset); la
#          tricolor cordobesa «debe haber sido abandonada antes de marzo de 1854» (Prando 2009); la
#          santafesina se abandono en 1880 (Wikipedia ES).
#       20 solo Tucuman, Salta, Jujuy, Catamarca y La Rioja: la celeste mientras la Coalicion del Norte
#          siga en pie y la provincia este de su lado, sin nadie encima. «Tucuman cambio de bandera al
#          cambiar de bando». Las provincias batidas nacen provincias del Pacto bajo Buenos Aires, asi que bajo
#          el Pacto llevan la federal.
#       30 y 31 la bandera provincial de hoy, desde la fecha de la ley que la adopto.
#       40 mientras siga la confederacion, la PRIMERA bandera provincial de la provincia, sea de la fecha que
#          sea (Juan, 24/9/2026; anacronismo a proposito). Lo mismo para los nueve territorios y para Corrientes y
#          Entre Rios, al final del archivo.
#     Ningun otro mod del playset define estos once tags en flag_definitions (verificado el 22/9/2026
#     contra todo el Workshop descargado, incluidas las listas REPLACE_OR_CREATE de DNFC), asi que un
#     bloque comun no se descarta al cargar.
# -------------------------------------------------------------------------------------------------

		coa = gg_flag_argentina_celeste
		priority = 10
		trigger = {
			game_date >= 1852.2.3
		}

		priority = 20
		trigger = {
			c:CLN ?= { is_subject = no }
