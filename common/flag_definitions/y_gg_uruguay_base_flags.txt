# EN: 25/9/2026 -- URUGUAY'S BASE LIST: the base game's URU flag definitions, unchanged (00_flag_definitions.txt, 1.13).
#     REPLACE, not a plain block: vanilla already defines URU and a second «URU = {» is dropped at load («Duplicated key
#     URU will not be created»). The REPLACE also drops More Dynamic Names And Flags' INJECT_OR_CREATE:URU, whose
#     URU_cisplatina would fly for any subject of Brazil (AUD-CIS-PUPPET: a protectorate of the Empire is a Republic, not
#     the Cisplatine Province).
#     THE FILE NAME IS THE MECHANISM. Flag definition files load in file-name order across every mod, and a REPLACE drops
#     every list read before it. «y_» sorts after more_dynamic_names.txt and BEFORE Dynamic Names, Flags & Colours'
#     z_dnfc_brazil_flag_definitions.txt (REPLACE_OR_CREATE:URU). So:
#       - without DNFC this is the list, as it has been since 22/9/2026;
#       - with DNFC, DNFC's list replaces this one and stays whole: its subject, republic, dictatorship, oligarchy,
#         theocracy, communist and anarchist flags.
#     Either way zzz_gg_uruguay_flags.txt INJECTs the mod's own definitions on top. Until 25/9/2026 this list sat in
#     zz_guerra_grande_flags.txt, which sorts after DNFC's file: with DNFC it wiped DNFC's list, and Juan's local compatch
#     (la-argentina-x-dnfc, retired that day) had to rebuild it.
# ES: LA LISTA BASE DEL URUGUAY: la del juego base, sin cambios. REPLACE porque vanilla ya define URU y un segundo «URU = {»
#     se descarta; tambien borra el INJECT_OR_CREATE:URU de More Dynamic Names (su URU_cisplatina saldria para cualquier
#     sujeto del Brasil). EL NOMBRE DEL ARCHIVO ES EL MECANISMO: los archivos se leen por orden de nombre entre todos los
#     mods y un REPLACE borra lo leido antes. «y_» va despues de more_dynamic_names.txt y ANTES del
#     z_dnfc_brazil_flag_definitions.txt de DNFC: sin DNFC esta es la lista; con DNFC, la de DNFC la reemplaza y queda
#     entera. En los dos casos zzz_gg_uruguay_flags.txt suma arriba las definiciones del mod. Hasta el 25/9/2026 esta lista
#     estaba en zz_guerra_grande_flags.txt, que va despues de DNFC: borraba la de DNFC y el compatch local la rearmaba.
