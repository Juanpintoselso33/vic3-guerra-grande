# EN: THE BIRTH OF THE THREE ARGENTINE COUNTRIES, as effects, so the events stay readable.
#
#     THE CLONE RULE, and why it is not the one the audit proposed. create_country copies the origin
#     country's entire character roster, and a clone shares its template with the original, so you
#     cannot tell them apart by template. The proposed fix was to compare identities -- purge every
#     character with template X that is NOT the saved scope. That works, but it needs one comparison
#     per person and it is silently wrong the day somebody adds a character and forgets the list.
#     What these effects do instead: KILL EVERY CLONE, WITHOUT EXCEPTION, the moment the country is
#     created, and only then bring in the people who belong to it -- the originals, transferred, and
#     the new ones, created. Nothing to compare and no list to keep.
#     It used to EXILE them, and this paragraph used to say that no clone could survive it. That was
#     wrong: vanilla's exile makes an agitator out of the man and leaves him alive in the exile pool,
#     where any country can pick him up. Corrected 20 September 2026; the detail is in
#     gg_argentina_new_country_people.
#     The order matters and is the whole trick: create, empty, populate, name the ruler.
# ES: EL NACIMIENTO DE LOS TRES PAISES ARGENTINOS, como efectos, para que los eventos se lean.
#
#     LA REGLA DEL CLON, y por que no es la que proponia la auditoria. create_country copia el
#     plantel entero de personajes del pais de origen, y un clon comparte template con el original,
#     asi que no se los puede distinguir por template. El arreglo propuesto era comparar identidades:
#     purgar todo personaje con template X que NO sea el scope guardado. Funciona, pero necesita una
#     comparacion por persona y se equivoca en silencio el dia que alguien agrega un personaje y se
#     olvida de la lista.
#     Lo que hacen estos efectos: MATAR A TODOS LOS CLONES, SIN EXCEPCION, apenas se crea el pais, y
#     recien despues traer a los que le pertenecen -- los originales, transferidos, y los nuevos,
#     creados. Nada que comparar y ninguna lista que mantener.
#     Antes los EXILIABA, y este parrafo decia que asi ningun clon podia sobrevivir. Estaba mal: el
#     exilio de vanilla lo convierte en agitador y lo deja vivo en la bolsa de exiliados, de donde
#     cualquier pais lo puede levantar. Corregido el 20/9/2026; el detalle esta en
#     gg_argentina_new_country_people.
#     El orden importa y es todo el truco: crear, vaciar, poblar, nombrar gobernante.
# -------------------------------------------------------------------------------------------------

# EN/ES: 6/3/1839 -- Corrientes se separa. Se lleva Corrientes y Misiones.
gg_argentina_create_corrientes = {
	debug_log = "GG_EF|[TimeKeeper.GetCurrentDate.GetString]|gg_argentina_create_corrientes|" # GG_TRAZA
	create_country = {
		tag = CRR
		origin = this
		state = s:STATE_CORRIENTES.region_state:ARG
		# EN/ES: 23/9/2026 (graph H1) -- the role mark gg_arg_corrientes_seat was set here and read nowhere
		#     since 19/9 (the calendar addresses Corrientes as c:CRR, which a revival keeps); removed
		#     / la marca de rol se ponia aca y nada la leia; el calendario va por c:CRR, que el renacimiento conserva
	}
	# EN: MISIONES AND THE EASTERN MISSIONS GO WITH IT. Corrientes had occupied the land south of the
	#     Aguapey since 1830, handed it out in enfiteusis and claimed the whole territory on 1
	#     September 1832 -- and that claim did not stop at the Uruguay. «La Argentina» models it: it
	#     gives Rosas three provinces inside STATE_PARANA and two inside STATE_SANTA_CATARINA, which
	#     are the Misiones Orientales, the ground Argentina claimed from Brazil. They are the same
	#     claim as Misiones and they belong to whoever holds the Misiones claim.
	#     Juan caught this on 20/9/2026 playing Argentina: «le faltan states que el mod de la
	#     argentina le da, argentinian santa catarina y argentinian parana».
	# ES: MISIONES Y LAS MISIONES ORIENTALES SE VAN CON ELLA. Corrientes ocupaba el territorio al sur
	#     del Aguapey desde 1830, lo repartio en enfiteusis y reivindico el territorio entero el
	#     1/9/1832 -- y esa reivindicacion no se detenia en el Uruguay. «La Argentina» lo modela: le da
	#     a Rosas tres provincias adentro de STATE_PARANA y dos adentro de STATE_SANTA_CATARINA, que
	#     son las Misiones Orientales, la tierra que la Argentina le reclamaba al Brasil. Son la misma
	#     reivindicacion que Misiones y le corresponden a quien tenga esa reivindicacion.
	#     Lo agarro Juan el 20/9/2026 jugando de Argentina: «le faltan states que el mod de la
	#     argentina le da, argentinian santa catarina y argentinian parana».
	if = {
		limit = { exists = s:STATE_MISIONES.region_state:ARG }
		s:STATE_MISIONES.region_state:ARG = { set_state_owner = c:CRR }
	}
	if = {
		limit = { exists = s:STATE_PARANA.region_state:ARG }
		s:STATE_PARANA.region_state:ARG = { set_state_owner = c:CRR }
	}
	if = {
		limit = { exists = s:STATE_SANTA_CATARINA.region_state:ARG }
		s:STATE_SANTA_CATARINA.region_state:ARG = { set_state_owner = c:CRR }
	}
	gg_argentina_new_country_people = {
		TAG = CRR
	}
	c:CRR ?= {
		set_capital = STATE_CORRIENTES
		# EN/ES: Beron de Astrada, que se separo y murio mandando veinticinco dias despues
		# EN/ES: 22/9/2026 -- he already governs Corrientes inside the Confederation from 1836: fetched,
		#     not copied / ya gobierna Corrientes dentro de la Confederacion desde 1836: se lo trae, no se lo copia
		gg_ruler_set = { TEMPLATE = CRR_gg_genaro_beron_de_astrada }
	}
	# EN/ES: y la delegacion: una provincia menos / and the delegation: one province fewer
	gg_delegation_revoked = { KEY = corrientes COUNT = -1 }
	# EN: the army that came apart at Pago Largo twenty-five days later. Modest on purpose: it was a
	#     provincial army with no allies, and the sources are blunt about the result.
	#     The HQ uses an owned state: the mod already lost Brown's whole
	#     squadron to a hardcoded region that contained none of the country's states.
	# ES: el ejercito que se deshizo en Pago Largo veinticinco dias despues. Modesto a proposito: era
	#     un ejercito provincial sin aliados, y las fuentes son tajantes sobre el resultado.
	#     El cuartel usa un estado propio: el mod ya perdio la
	#     escuadra de Brown entera por una region cableada que no tenia ningun estado del pais.
	c:CRR ?= {
		gg_select_formation_hq_state = yes
		# EN: Without an owned state there is no valid HQ; skip this formation.
		# ES: Sin un estado propio no hay cuartel valido; se omite esta formacion.
		if = {
			limit = { exists = scope:gg_formation_hq_state }
			create_military_formation = {
				type = army
				hq_region = scope:gg_formation_hq_state.region
				name = gg_arg_ejercito_correntino
				combat_unit = {
					type = unit_type:combat_unit_type_irregular_infantry
					state_region = scope:gg_formation_hq_state.state_region
					count = 4
				}
				# EN: THE CORRENTINE HORSE, and it is bigger than it was until 20/9/2026. The army that
				#     came apart at Pago Largo was modest, and it was written modest on purpose -- but a
				#     province that can be put down in three months is not a war, it is an errand, and
				#     that is what Juan found playing Rosas. Corrientes fought this war for eight years,
				#     beat Echague at Caa Guazu and was still fighting at Vences in 1847. Its strength was
				#     always the horse: the litoral raised cavalry, not battalions.
				# ES: LA CABALLERIA CORRENTINA, y es mas grande de lo que era hasta el 20/9/2026. El
				#     ejercito que se deshizo en Pago Largo era modesto, y estaba escrito modesto a
				#     proposito -- pero una provincia que se liquida en tres meses no es una guerra, es un
				#     mandado, y eso fue lo que Juan se encontro jugando de Rosas. Corrientes peleo esta
				#     guerra ocho anios, le gano a Echague en Caa Guazu y seguia peleando en Vences en
				#     1847. Su fuerza fue siempre la caballeria: el litoral levantaba jinetes, no
				#     batallones.
				combat_unit = {
					type = unit_type:combat_unit_type_hussars
					state_region = scope:gg_formation_hq_state.state_region
					count = 6
				}
				combat_unit = {
					type = unit_type:combat_unit_type_cannon_artillery
					state_region = scope:gg_formation_hq_state.state_region
					count = 1
				}
			}
		}
	}
	# EN/ES: Ferre no es el gobernante: es el hombre del programa fluvial, y su programa es la razon
	#     de la guerra / Ferre is not the ruler: he is the man of the river programme
	if = {
		limit = { exists = scope:gg_ferre }
		scope:gg_ferre = { transfer_character = c:CRR }
	}
}

# EN/ES: 7/4/1840 -- Tucuman se pronuncia. Salta, Jujuy, Catamarca y La Rioja dentro del mes.
gg_argentina_create_coalicion = {
	debug_log = "GG_EF|[TimeKeeper.GetCurrentDate.GetString]|gg_argentina_create_coalicion|" # GG_TRAZA
	create_country = {
		tag = CLN
		origin = this
		state = s:STATE_TUCUMAN.region_state:ARG
		on_created = {
			set_variable = gg_arg_coalicion_seat
		}
	}
	c:CLN ?= { gg_argentina_rebel_diplomacy_reset = yes }
	# EN: the four that followed within the month. Santiago del Estero is NOT here and must never be:
	#     Ibarra refused flatly, and that refusal is what cuts the bloc in two on the map.
	# ES: las cuatro que la siguieron dentro del mes. Santiago del Estero NO esta aca y no tiene que
	#     estar nunca: Ibarra se nego de plano, y esa negativa es lo que parte el bloque en dos en el
	#     mapa.
	if = {
		limit = { exists = s:STATE_SALTA.region_state:ARG }
		s:STATE_SALTA.region_state:ARG = { set_state_owner = c:CLN }
	}
	if = {
		limit = { exists = s:STATE_JUJUY.region_state:ARG }
		s:STATE_JUJUY.region_state:ARG = { set_state_owner = c:CLN }
	}
	if = {
		limit = { exists = s:STATE_CATAMARCA.region_state:ARG }
		s:STATE_CATAMARCA.region_state:ARG = { set_state_owner = c:CLN }
	}
	if = {
		limit = { exists = s:STATE_LA_RIOJA.region_state:ARG }
		s:STATE_LA_RIOJA.region_state:ARG = { set_state_owner = c:CLN }
	}
	# EN/ES: 23/9/2026 (Juan) -- Tarija, when Buenos Aires holds it, is Salta's (gg_province_cells.txt):
	#     if Salta rises with the Coalition, Tarija goes with it / si Salta se alza, Tarija va con ella
	if = {
		limit = { exists = s:STATE_TARIJA.region_state:ARG exists = s:STATE_SALTA.region_state:CLN }
		s:STATE_TARIJA.region_state:ARG = { set_state_owner = c:CLN }
	}
	gg_argentina_new_country_people = {
		TAG = CLN
	}
	c:CLN ?= {
		set_capital = STATE_TUCUMAN
		# EN: Avellaneda rules at the birth, and that is the point: on 7 April 1840 the head of the
		#     pronouncement is a lawyer and a journalist, not a caudillo. Brizuela was made Director
		#     of the League later, with the power to make war, sign peace and negotiate loans -- that
		#     is its own event, on 24 September 1840, still to write.
		# ES: Avellaneda gobierna en el nacimiento, y eso es justamente el punto: el 7 de abril de
		#     1840 la cabeza del pronunciamiento es un abogado y periodista, no un caudillo. A
		#     Brizuela lo nombran Director de la Liga despues, con facultad de hacer la guerra, firmar
		#     la paz y negociar emprestitos: es su propio evento, del 24/9/1840, y falta escribirlo.
		# EN/ES: 22/9/2026 -- he exists in the Confederation from 1836: fetched, not copied / se lo trae
		gg_ruler_set = { TEMPLATE = CLN_gg_marco_avellaneda }
		# EN/ES: 22/9/2026 -- Brizuela governs La Rioja from 1837 on the Pact's list: fetched, not copied,
		#     and his command back (he was born in Buenos Aires's roster without one)
		#     / gobierna La Rioja desde 1837 en la lista del Pacto: se lo trae, no se lo copia, y recupera el mando
		gg_character_fetch = { TEMPLATE = CLN_gg_tomas_brizuela }
		random_scope_character = {
			limit = { has_template = CLN_gg_tomas_brizuela NOT = { has_role = character_role_general } }
			add_character_role = general
		}
	}
	# EN: one province per state that ACTUALLY left. The four transfers above are conditional -- if
	#     Argentina had already lost Salta, that state never moves -- so a flat -5 would charge Rosas
	#     for delegations he had already lost. Tucuman is unconditional: without it there is no
	#     Coalition, and the relay guarantees Argentina still held it.
	# ES: una provincia por cada estado que SE FUE DE VERDAD. Las cuatro transferencias de arriba son
	#     condicionales -- si la Argentina ya habia perdido Salta, ese estado no se mueve nunca --,
	#     asi que un -5 fijo le cobraria a Rosas delegaciones que ya habia perdido. Tucuman va sin
	#     condicion: sin ella no hay Coalicion, y el relevo garantiza que la Argentina la tenia.
	gg_delegation_revoked = { KEY = coalicion_tucuman COUNT = -1 }
	if = {
		limit = { exists = s:STATE_SALTA.region_state:CLN }
		gg_delegation_revoked = { KEY = coalicion_salta COUNT = -1 }
	}
	if = {
		limit = { exists = s:STATE_JUJUY.region_state:CLN }
		gg_delegation_revoked = { KEY = coalicion_jujuy COUNT = -1 }
	}
	if = {
		limit = { exists = s:STATE_CATAMARCA.region_state:CLN }
		gg_delegation_revoked = { KEY = coalicion_catamarca COUNT = -1 }
	}
	if = {
		limit = { exists = s:STATE_LA_RIOJA.region_state:CLN }
		gg_delegation_revoked = { KEY = coalicion_la_rioja COUNT = -1 }
	}
	# EN/ES: Brizuela tenia en La Rioja "el Ejercito mas numeroso y mejor armado de la Coalicion" y la
	#     oficialidad mas destacada; por eso lo hicieron Director / the largest and best armed army
	c:CLN ?= {
		gg_select_formation_hq_state = yes
		# EN: Without an owned state there is no valid HQ; skip this formation.
		# ES: Sin un estado propio no hay cuartel valido; se omite esta formacion.
		if = {
			limit = { exists = scope:gg_formation_hq_state }
			create_military_formation = {
				type = army
				hq_region = scope:gg_formation_hq_state.region
				name = gg_arg_ejercito_coalicion
				combat_unit = {
					type = unit_type:combat_unit_type_line_infantry
					state_region = scope:gg_formation_hq_state.state_region
					count = 3
				}
				combat_unit = {
					type = unit_type:combat_unit_type_irregular_infantry
					state_region = scope:gg_formation_hq_state.state_region
					count = 2
				}
				combat_unit = {
					type = unit_type:combat_unit_type_hussars
					state_region = scope:gg_formation_hq_state.state_region
					count = 3
				}
				combat_unit = {
					type = unit_type:combat_unit_type_cannon_artillery
					state_region = scope:gg_formation_hq_state.state_region
					count = 1
				}
			}
		}
	}
	# EN: If Rosas sent Lamadrid in March, the saved original defects; if he retained him there is no
	#     saved scope and no transfer. ES: Si Rosas mando a Lamadrid en marzo, se pasa el original
	#     guardado; si lo retuvo no hay scope guardado ni transferencia.
	if = {
		limit = { exists = scope:gg_lamadrid }
		scope:gg_lamadrid = { transfer_character = c:CLN }
	}
}

# EN: A country created from Argentina must not inherit the parent country's friendly military
#     network. The northern coalition is an uprising, so it begins hostile to Buenos Aires and
#     without inherited alliances, defensive pacts or guarantees that can pull Peru/Bolivia in.
# ES: Un pais creado desde la Argentina no debe heredar su red militar amistosa. La Coalicion del
#     Norte es un levantamiento: nace hostil a Buenos Aires y sin alianzas, pactos defensivos ni
#     garantias heredadas que puedan arrastrar al Peru o Bolivia.
gg_argentina_rebel_diplomacy_reset = {
	debug_log = "GG_EF|[TimeKeeper.GetCurrentDate.GetString]|gg_argentina_rebel_diplomacy_reset|" # GG_TRAZA
	set_variable = gg_rebel_diplomacy_reset
	save_scope_as = gg_rebel_country
	# EN: 22/9/2026 -- alliances, defensive pacts and guarantees are treaty articles since 1.10. The
	#     rebel withdraws from any treaty carrying one of them, the pattern Gates of the Bosphorus uses
	#     for Montenegro (2-03_balkfm_montenegro.txt) and vanilla's DLC for the Roman Republic
	#     (italian_unification.txt): every_scope_treaty + withdraw. No break penalties: the rebel did
	#     not sign them. Withdrawing leaves the whole treaty, so an economic rider inherited in the
	#     same treaty goes too: acceptable for an uprising born at war with Buenos Aires (Codex 22/9).
	# ES: alianzas, pactos defensivos y garantias son articulos de tratado desde la 1.10. El rebelde se
	#     retira de todo tratado que lleve alguno, con el patron que usa Gates of the Bosphorus para
	#     Montenegro y el DLC de vanilla para la Republica Romana. Sin penalidad: no los firmo el.
	every_scope_treaty = {
		limit = {
			any_scope_article = {
				OR = {
					has_type = alliance
					has_type = defensive_pact
					has_type = guarantee_independence
				}
				# EN/ES: Codex 22/9 -- only articles the rebel is party to, not someone else's in a
				#     multilateral treaty / solo articulos de los que el rebelde es parte
				OR = {
					source_country = scope:gg_rebel_country
					target_country = scope:gg_rebel_country
				}
			}
		}
		withdraw = {
			country = scope:gg_rebel_country
		}
	}
	if = {
		limit = { exists = c:ARG }
		change_relations = { country = c:ARG value = -100 }
		set_mutual_secret_goal = { country = c:ARG secret_goal = conquer }
	}
	clear_saved_scope = gg_rebel_country
}

# EN: 23/9/2026 (AUD-SEAT-ALCARAZ) -- the Entre Rios state that still answers to Rosas, saved as gg_entre_rios_state:
#     Buenos Aires's own ground, or the loyal Entre Rios of Alcaraz (gg_entre_rios_alcaraz_loyal). Used by the orders
#     of 1847-1851 wherever they reach Urquiza. Nothing is saved when neither holds.
# ES: el estado de Entre Rios que todavia responde a Rosas: suelo de Buenos Aires o el Entre Rios leal de Alcaraz.
gg_save_entre_rios_rosas_state = {
	if = {
		limit = { exists = s:STATE_ENTRE_RIOS.region_state:ARG }
		s:STATE_ENTRE_RIOS.region_state:ARG = { save_scope_as = gg_entre_rios_state }
	}
	else_if = {
		limit = { gg_entre_rios_alcaraz_loyal = yes }
		s:STATE_ENTRE_RIOS.region_state:ENR = { save_scope_as = gg_entre_rios_state }
	}
}

# EN: THE TWO ORDERS LEAVE AN ARMY ON THE MAP. Giving Urquiza the Brazilian command forms the
#     force in Entre Rios and puts him at its head; withholding it forms the same national force in
#     Buenos Aires under another serving general. The unit counts are game-scale consequences, not
#     a sourced order of battle, and no alternative commander is named because the research does
#     not provide one.
# ES: LAS DOS ORDENES DEJAN UN EJERCITO EN EL MAPA. Darle a Urquiza el mando contra el Brasil forma
#     la fuerza en Entre Rios y lo pone a su frente; negarselo forma la misma fuerza nacional en
#     Buenos Aires bajo otro general en servicio. Las cantidades son consecuencias a escala de
#     juego, no un orden de batalla documentado, y no se nombra al mando alternativo porque la
#     investigacion no aporta uno.
# SOURCE / FUENTE: docs/guerra-grande-argentina/historia-argentina.md, «Urquiza y Entre Rios» y
# «Los momentos de decision», punto 7 [D].
# -------------------------------------------------------------------------------------------------
gg_argentina_arm_urquiza_against_brazil = {
	debug_log = "GG_EF|[TimeKeeper.GetCurrentDate.GetString]|gg_argentina_arm_urquiza_against_brazil|" # GG_TRAZA
	# EN/ES: 23/9 (AUD-SEAT-ALCARAZ) -- Buenos Aires's Entre Rios, or the loyal Entre Rios of Alcaraz when the order
	#     reaches Urquiza there (the caller is then c:ENR) / o el Entre Rios leal de Alcaraz, y el que llama es c:ENR
	gg_save_entre_rios_rosas_state = yes
	create_military_formation = {
		type = army
		hq_region = scope:gg_entre_rios_state.region
		name = gg_arg_ejercito_brasil_urquiza
		save_scope_as = gg_brazil_army
		combat_unit = {
			type = unit_type:combat_unit_type_line_infantry
			state_region = s:STATE_ENTRE_RIOS
			count = 4
		}
		combat_unit = {
			type = unit_type:combat_unit_type_irregular_infantry
			state_region = s:STATE_ENTRE_RIOS
			count = 2
		}
		combat_unit = {
			type = unit_type:combat_unit_type_hussars
			state_region = s:STATE_ENTRE_RIOS
			count = 4
		}
		combat_unit = {
			type = unit_type:combat_unit_type_cannon_artillery
			state_region = s:STATE_ENTRE_RIOS
			count = 2
		}
	}
	random_scope_character = {
		limit = { has_template = ARG_Justo_Jose_de_Urquiza }
		if = {
			limit = { NOT = { has_role_of_type = general } }
			add_character_role = general
			set_commander_rank = 2
		}
		transfer_to_formation = scope:gg_brazil_army
	}
	# EN/ES: 23/9 (AUD-SEAT-ALCARAZ-ORDERS) -- an army of Entre Rios's own: the Pronouncement raises no second one
	#     / un ejercito propio de Entre Rios: el Pronunciamiento no levanta otro
	if = {
		limit = { c:ENR ?= this exists = scope:gg_brazil_army }
		set_variable = gg_enr_orders_army
	}
}

gg_argentina_alcaraz_seat = {
	debug_log = "GG_EF|[TimeKeeper.GetCurrentDate.GetString]|gg_argentina_alcaraz_seat|" # GG_TRAZA
	if = {
		limit = {
			c:ARG ?= this
			NOT = { exists = c:ENR }
			exists = s:STATE_ENTRE_RIOS.region_state:ARG
		}
		random_scope_character = {
			limit = { has_template = ARG_Justo_Jose_de_Urquiza }
			save_scope_as = gg_urquiza_alcaraz
		}
		create_country = {
			tag = ENR
			origin = this
			state = s:STATE_ENTRE_RIOS.region_state:ARG
			on_created = {
				set_variable = gg_arg_entre_rios_seat
				set_variable = gg_enr_alcaraz_seat
			}
		}
		gg_argentina_new_country_people = { TAG = ENR }
		c:ENR ?= {
			set_capital = STATE_ENTRE_RIOS
			if = {
				limit = { exists = scope:gg_urquiza_alcaraz }
				scope:gg_urquiza_alcaraz = {
					transfer_character = c:ENR
					set_character_as_ruler = yes
				}
			}
			else = {
				create_character = { template = ARG_Justo_Jose_de_Urquiza ruler = yes }
			}
		}
		if = {
			limit = { exists = c:ENR }
			# EN/ES: 24/9 (AUD-VASSAL-RECOGNIZED) -- the Province of the Pact, not a protectorate: no rank rule (a province can reach minor_power like Buenos Aires) / provincia del Pacto, no protectorado: sin la regla del rango
			create_diplomatic_pact = { country = c:ENR type = gg_pact_province }
			gg_subject_watch = { SUBJECT = c:ENR }
		}
	}
}

# EN: THE EMPTYING. Called right after create_country and before anybody is brought in: every

#     que trajo el clonado se va al exilio. Es deliberadamente bruto -- sin excepciones, sin lista --

			#     replace_character_roles = { add = { agitator } remove_all = yes }. Nothing dies.

			#     some thirty ghosts, and one of them is named Juan Manuel de Rosas.

			# ES: LOS CLONES SE MATAN, NO SE EXILIAN, y la correccion es del 20/9/2026, de la revision

# EN: THE WAR THE TEXT PROMISES. Every one of these three events tells the player a province has
#     disavowed Buenos Aires and, in the Corrientes case, declared war outright -- and until now not

gg_argentina_open_war = {
	debug_log = "GG_EF|[TimeKeeper.GetCurrentDate.GetString]|gg_argentina_open_war|" # GG_TRAZA
	if = {
		limit = {
			exists = c:$TAG$
			c:ARG ?= this
			NOT = { has_war_with = c:$TAG$ }
			NOT = { is_diplomatic_play_enemy_of = c:$TAG$ }
			NOT = { has_truce_with = c:$TAG$ }
			c:$TAG$ ?= { is_subject = no }
			OR = {
				NOT = { c:CRR ?= c:$TAG$ }
				NOT = { has_global_variable = gg_corrientes_recovery }
			}
		}
		# EN: NOT AN ANNEXATION. Rosas never annexed Corrientes and never annexed Tucuman. After Pago
		#     Largo he put a federal governor in the city and the province went on existing; after
		#     Famailla, Celedonio Gutierrez governed Tucuman for eleven years. What was taken back was
		#     never the ground -- it was the CHARGE, the conduct of foreign relations, which is the
		#     one thing the Federal Pact ever delegated.
		#     So the play is a protectorate, and that is not a euphemism: a protectorate is a country
		#     whose foreign relations are conducted by another, which is the exact definition of the
		#     delegation this whole side is built on. Winning puts the province back under the pact.
		#     It also fixes what Juan hit on 20/9/2026 playing Argentina -- «no me convence este
		#     sistema de que Corrientes aparezca y la desaparezca yo a los 3 meses». A province that
		#     is beaten and not erased is a province that can rise again, and Corrientes rose three
		#     times: in 1839, at Caa Guazu in 1841 and at the Paso de los Libres in 1843.
		# ES: NO ES UNA ANEXION. Rosas no anexo nunca a Corrientes ni a Tucuman. Despues de Pago Largo
		#     puso un gobernador federal en la ciudad y la provincia siguio existiendo; despues de
		#     Famailla, Celedonio Gutierrez goberno Tucuman once anios. Lo que se recuperaba no era
		#     nunca la tierra: era el ENCARGO, el manejo de las relaciones exteriores, que es lo unico
		#     que el Pacto Federal delego jamas.
		#     Asi que la jugada es un protectorado, y no es un eufemismo: un protectorado es un pais
		#     cuyas relaciones exteriores lleva otro, que es la definicion exacta de la delegacion
		#     sobre la que esta construido todo este lado. Ganar devuelve la provincia al pacto.
		#     Ademas arregla lo que Juan se encontro el 20/9/2026 jugando de Argentina -- «no me
		#     convence este sistema de que Corrientes aparezca y la desaparezca yo a los 3 meses». Una
		#     provincia batida y no borrada es una provincia que se puede volver a alzar, y Corrientes
		#     se alzo tres veces: en 1839, en Caa Guazu en 1841 y en el Paso de los Libres en 1843.
		# EN: 22/9/2026 (Juan): the Coalition too is fought for a protectorate, and a beaten Coalition is
		#     split into its provinces, each a protectorate of Buenos Aires (gg_argentina_split_coalition).
		#     The league still dissolves -- decisiones-argentina.md, 12 -- but into provinces under federal
		#     governors, not into Buenos Aires's own ground. dp_gg_liga_disuelta is retired.
		# ES: la Coalicion tambien se pelea por un protectorado, y batida se parte en sus provincias, cada
		#     una protectorado de Buenos Aires. La liga se sigue disolviendo, pero en provincias con
		#     gobernador federal, no en suelo de Buenos Aires. dp_gg_liga_disuelta se retira.
		# EN: 25/9/2026 (AUD-PACT-PLAY-BACKDOWN) -- the war of the Pronouncement (Entre Rios, gg_argentina.3.b/.c, which set
		#     gg_war_against_buenos_aires first) opens as a WAR, with no play stage. As a play it sat a hundred days (to
		#     9/8/1851 in every headless trace) and an AI side could back down: in 4 of 40 traces it did (sweep 25/9,
		#     traza_20260925-191226: Entre Rios backed down on 7/7/1851, Rosas's protectorate was enforced, gg_caseros.6 read
		#     it as his victory). The tilt (gg_caseros.8) and the guard (gg_caseros.9) act on war support, which a play does
		#     not have. Historically there was no such stage: Rosas answered the Pronouncement as a rebellion, and Urquiza
		#     was in arms from May 1851. escalation = 100: the play is born at its end, so nothing that joins plays in
		#     their escalation (another mod's treaty obligations) drags a third country into the Confederation's internal
		#     war, which nobody may join (dp_gg_pacto_federal). The other Pact wars (Corrientes, the Coalition) keep
		#     their play stage.
		# ES: la guerra del Pronunciamiento (Entre Rios) se abre como GUERRA, sin etapa de jugada. Como jugada duraba cien
		#     dias y un lado de la IA podia retroceder: en 4 de 40 trazas lo hizo (Entre Rios el 7/7/1851, se impuso el
		#     protectorado de Rosas). La inclinacion y la guardia actuan sobre el apoyo a la guerra, que una jugada no
		#     tiene. Historicamente no hubo esa etapa: Rosas contesto con la guerra y Urquiza estuvo en armas desde mayo.
		#     escalation = 100 para que nada que sume paises a jugadas en escalada meta a un tercero en una guerra
		#     interna. Las otras guerras del Pacto conservan su jugada.
		if = {
			limit = {
				c:ENR ?= c:$TAG$

				name = gg_argentina_play_$TAG$
				target_country = c:$TAG$
				type = dp_gg_pacto_federal
				escalation = 100
				war = yes
			}
		}
		else = {
			create_diplomatic_play = {
				name = gg_argentina_play_$TAG$
				target_country = c:$TAG$
				type = dp_gg_pacto_federal
			}
		}
	}
