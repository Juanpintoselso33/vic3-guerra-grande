# -------------------------------------------------------------------------------------------------
# EN: THE BIRTH OF THE THREE ARGENTINE COUNTRIES, as effects, so the events stay readable.
#
#     THE CLONE RULE, and why it is not the one the audit proposed. create_country copies the origin
#     country's entire character roster, and a clone shares its template with the original, so you
#     cannot tell them apart by template. The proposed fix was to compare identities -- purge every
#     character with template X that is NOT the saved scope. That works, but it needs one comparison
#     per person and it is silently wrong the day somebody adds a character and forgets the list.
#     What these effects do instead: KILL EVERY CLONE, WITHOUT EXCEPTION, the moment the country is
#     created, and only then bring in the people who belong to it -- the originals, transferred, and
#     the new ones, created. Nothing to compare and no list to keep.
#     It used to EXILE them, and this paragraph used to say that no clone could survive it. That was
#     wrong: vanilla's exile makes an agitator out of the man and leaves him alive in the exile pool,
#     where any country can pick him up. Corrected 20 September 2026; the detail is in
#     gg_argentina_new_country_people.
#     The order matters and is the whole trick: create, empty, populate, name the ruler.
# ES: EL NACIMIENTO DE LOS TRES PAISES ARGENTINOS, como efectos, para que los eventos se lean.
#
#     LA REGLA DEL CLON, y por que no es la que proponia la auditoria. create_country copia el
#     plantel entero de personajes del pais de origen, y un clon comparte template con el original,
#     asi que no se los puede distinguir por template. El arreglo propuesto era comparar identidades:
#     purgar todo personaje con template X que NO sea el scope guardado. Funciona, pero necesita una
#     comparacion por persona y se equivoca en silencio el dia que alguien agrega un personaje y se
#     olvida de la lista.
#     Lo que hacen estos efectos: MATAR A TODOS LOS CLONES, SIN EXCEPCION, apenas se crea el pais, y
#     recien despues traer a los que le pertenecen -- los originales, transferidos, y los nuevos,
#     creados. Nada que comparar y ninguna lista que mantener.
#     Antes los EXILIABA, y este parrafo decia que asi ningun clon podia sobrevivir. Estaba mal: el
#     exilio de vanilla lo convierte en agitador y lo deja vivo en la bolsa de exiliados, de donde
#     cualquier pais lo puede levantar. Corregido el 20/9/2026; el detalle esta en
#     gg_argentina_new_country_people.
#     El orden importa y es todo el truco: crear, vaciar, poblar, nombrar gobernante.
# -------------------------------------------------------------------------------------------------

# EN/ES: 6/3/1839 -- Corrientes se separa. Se lleva Corrientes y Misiones.
gg_argentina_create_corrientes = {
	create_country = {
		tag = CRR
		origin = this
		state = s:STATE_CORRIENTES.region_state:ARG
		on_created = {
			# EN/ES: la variable de ROL, no de tag: el calendario argentino se dirige por rol, porque
			#     un asiento puede cambiar de manos / the ROLE variable, not the tag
			set_variable = gg_arg_corrientes_seat
		}
	}
	# EN/ES: Misiones se va con ella: ocupada desde 1830, repartida en enfiteusis, reivindicada
	#     entera el 1/9/1832 / Misiones goes with it
	if = {
		limit = { exists = s:STATE_MISIONES.region_state:ARG }
		s:STATE_MISIONES.region_state:ARG = { set_state_owner = c:CRR }
	}
	gg_argentina_new_country_people = {
		TAG = CRR
	}
	c:CRR ?= {
		set_capital = STATE_CORRIENTES
		# EN/ES: Beron de Astrada, que se separo y murio mandando veinticinco dias despues
		create_character = {
			template = CRR_gg_genaro_beron_de_astrada
			ruler = yes
		}
	}
	# EN/ES: y la delegacion: una provincia menos / and the delegation: one province fewer
	gg_delegation_revoked = { KEY = corrientes COUNT = -1 POINTS = -12 }
	# EN: the army that came apart at Pago Largo twenty-five days later. Modest on purpose: it was a
	#     provincial army with no allies, and the sources are blunt about the result.
	#     hq_region = capital.region, not a named strategic region: the mod already lost Brown's whole
	#     squadron to a hardcoded region that contained none of the country's states.
	# ES: el ejercito que se deshizo en Pago Largo veinticinco dias despues. Modesto a proposito: era
	#     un ejercito provincial sin aliados, y las fuentes son tajantes sobre el resultado.
	#     hq_region = capital.region, no una region estrategica con nombre: el mod ya perdio la
	#     escuadra de Brown entera por una region cableada que no tenia ningun estado del pais.
	c:CRR ?= {
		create_military_formation = {
			type = army
			hq_region = capital.region
			name = gg_arg_ejercito_correntino
			combat_unit = {
				type = unit_type:combat_unit_type_irregular_infantry
				count = 3
			}
			combat_unit = {
				type = unit_type:combat_unit_type_hussars
				count = 3
			}
		}
	}
	# EN/ES: Ferre no es el gobernante: es el hombre del programa fluvial, y su programa es la razon
	#     de la guerra / Ferre is not the ruler: he is the man of the river programme
	if = {
		limit = { exists = scope:gg_ferre }
		scope:gg_ferre = { transfer_character = c:CRR }
	}
}

# EN/ES: 7/4/1840 -- Tucuman se pronuncia. Salta, Jujuy, Catamarca y La Rioja dentro del mes.
gg_argentina_create_coalicion = {
	create_country = {
		tag = CLN
		origin = this
		state = s:STATE_TUCUMAN.region_state:ARG
		on_created = {
			set_variable = gg_arg_coalicion_seat
		}
	}
	# EN: the four that followed within the month. Santiago del Estero is NOT here and must never be:
	#     Ibarra refused flatly, and that refusal is what cuts the bloc in two on the map.
	# ES: las cuatro que la siguieron dentro del mes. Santiago del Estero NO esta aca y no tiene que
	#     estar nunca: Ibarra se nego de plano, y esa negativa es lo que parte el bloque en dos en el
	#     mapa.
	if = {
		limit = { exists = s:STATE_SALTA.region_state:ARG }
		s:STATE_SALTA.region_state:ARG = { set_state_owner = c:CLN }
	}
	if = {
		limit = { exists = s:STATE_JUJUY.region_state:ARG }
		s:STATE_JUJUY.region_state:ARG = { set_state_owner = c:CLN }
	}
	if = {
		limit = { exists = s:STATE_CATAMARCA.region_state:ARG }
		s:STATE_CATAMARCA.region_state:ARG = { set_state_owner = c:CLN }
	}
	if = {
		limit = { exists = s:STATE_LA_RIOJA.region_state:ARG }
		s:STATE_LA_RIOJA.region_state:ARG = { set_state_owner = c:CLN }
	}
	gg_argentina_new_country_people = {
		TAG = CLN
	}
	c:CLN ?= {
		set_capital = STATE_TUCUMAN
		# EN: Avellaneda rules at the birth, and that is the point: on 7 April 1840 the head of the
		#     pronouncement is a lawyer and a journalist, not a caudillo. Brizuela was made Director
		#     of the League later, with the power to make war, sign peace and negotiate loans -- that
		#     is its own event, on 24 September 1840, still to write.
		# ES: Avellaneda gobierna en el nacimiento, y eso es justamente el punto: el 7 de abril de
		#     1840 la cabeza del pronunciamiento es un abogado y periodista, no un caudillo. A
		#     Brizuela lo nombran Director de la Liga despues, con facultad de hacer la guerra, firmar
		#     la paz y negociar emprestitos: es su propio evento, del 24/9/1840, y falta escribirlo.
		create_character = {
			template = CLN_gg_marco_avellaneda
			ruler = yes
		}
		create_character = {
			template = CLN_gg_tomas_brizuela
		}
	}
	# EN: one province per state that ACTUALLY left. The four transfers above are conditional -- if
	#     Argentina had already lost Salta, that state never moves -- so a flat -5 would charge Rosas
	#     for delegations he had already lost. Tucuman is unconditional: without it there is no
	#     Coalition, and the relay guarantees Argentina still held it.
	# ES: una provincia por cada estado que SE FUE DE VERDAD. Las cuatro transferencias de arriba son
	#     condicionales -- si la Argentina ya habia perdido Salta, ese estado no se mueve nunca --,
	#     asi que un -5 fijo le cobraria a Rosas delegaciones que ya habia perdido. Tucuman va sin
	#     condicion: sin ella no hay Coalicion, y el relevo garantiza que la Argentina la tenia.
	gg_delegation_revoked = { KEY = coalicion_tucuman COUNT = -1 POINTS = -12 }
	if = {
		limit = { exists = s:STATE_SALTA.region_state:CLN }
		gg_delegation_revoked = { KEY = coalicion_salta COUNT = -1 POINTS = -12 }
	}
	if = {
		limit = { exists = s:STATE_JUJUY.region_state:CLN }
		gg_delegation_revoked = { KEY = coalicion_jujuy COUNT = -1 POINTS = -12 }
	}
	if = {
		limit = { exists = s:STATE_CATAMARCA.region_state:CLN }
		gg_delegation_revoked = { KEY = coalicion_catamarca COUNT = -1 POINTS = -12 }
	}
	if = {
		limit = { exists = s:STATE_LA_RIOJA.region_state:CLN }
		gg_delegation_revoked = { KEY = coalicion_la_rioja COUNT = -1 POINTS = -12 }
	}
	# EN/ES: Brizuela tenia en La Rioja "el Ejercito mas numeroso y mejor armado de la Coalicion" y la
	#     oficialidad mas destacada; por eso lo hicieron Director / the largest and best armed army
	c:CLN ?= {
		create_military_formation = {
			type = army
			hq_region = capital.region
			name = gg_arg_ejercito_coalicion
			combat_unit = {
				type = unit_type:combat_unit_type_line_infantry
				count = 3
			}
			combat_unit = {
				type = unit_type:combat_unit_type_irregular_infantry
				count = 2
			}
			combat_unit = {
				type = unit_type:combat_unit_type_hussars
				count = 3
			}
			combat_unit = {
				type = unit_type:combat_unit_type_cannon_artillery
				count = 1
			}
		}
	}
	# EN/ES: Lamadrid existe en vanilla y se paso a sus filas / Lamadrid exists in vanilla
	if = {
		limit = { exists = scope:gg_lamadrid }
		scope:gg_lamadrid = { transfer_character = c:CLN }
	}
}

# EN/ES: 1/5/1851 -- el Pronunciamiento de Urquiza.
gg_argentina_create_entre_rios = {
	create_country = {
		tag = ENR
		origin = this
		state = s:STATE_ENTRE_RIOS.region_state:ARG
		on_created = {
			set_variable = gg_arg_entre_rios_seat
		}
	}
	gg_argentina_new_country_people = {
		TAG = ENR
	}
	c:ENR ?= {
		set_capital = STATE_ENTRE_RIOS
	}
	# EN/ES: la que Rosas ofrecia todos los anios y esta vez le aceptaron / the one Rosas offered
	#     every year and this time they took
	gg_delegation_revoked = { KEY = entre_rios COUNT = -1 POINTS = -12 }
	# EN: the best army in the Confederation, and in a year it will be the Ejercito Grande that wins
	#     Caseros. Urquiza is NOT a general in vanilla -- he is an interest-group leader and a magnate
	#     -- so he is given a commander rank here: an Entre Rios whose ruler cannot take the field is
	#     an Entre Rios that cannot fight the war it just declared.
	# ES: el mejor ejercito de la Confederacion, y en un anio sera el Ejercito Grande que gana
	#     Caseros. Urquiza en vanilla NO es general -- es lider de grupo de interes y magnate --, asi
	#     que aca se le da rango de mando: un Entre Rios cuyo gobernante no puede salir a campania es
	#     un Entre Rios que no puede pelear la guerra que acaba de declarar.
	c:ENR ?= {
		create_military_formation = {
			type = army
			hq_region = capital.region
			name = gg_arg_ejercito_entrerriano
			combat_unit = {
				type = unit_type:combat_unit_type_line_infantry
				count = 4
			}
			combat_unit = {
				type = unit_type:combat_unit_type_irregular_infantry
				count = 2
			}
			combat_unit = {
				type = unit_type:combat_unit_type_hussars
				count = 4
			}
			combat_unit = {
				type = unit_type:combat_unit_type_cannon_artillery
				count = 2
			}
		}
	}
	# EN: the ORIGINAL Urquiza moves. Leaving the clone would give the game two of him, and every
	#     event that looks him up by template would find whichever one it found first.
	# ES: se muda el Urquiza ORIGINAL. Dejar el clon daria dos Urquizas, y cada evento que lo busca
	#     por template encontraria al que encontrara primero.
	if = {
		limit = { exists = scope:gg_urquiza }
		scope:gg_urquiza = {
			transfer_character = c:ENR
			set_character_as_ruler = yes
			# EN: and the command, which he does not have. Vanilla's Urquiza is an interest-group
			#     leader and a magnate, not a general (common/character_templates/country_arg.txt).
			#     An Entre Rios whose ruler cannot take the field cannot fight the war it just
			#     declared, and in a year this man has to win Caseros.
			#     This line was written once and silently lost: the edit that added it matched no
			#     text, because the army block had already changed what was around it. It is here
			#     now, and the review that caught it is in docs/guerra-grande-argentina/.
			# ES: y el mando, que no tiene. El Urquiza de vanilla es lider de grupo de interes y
			#     magnate, no general. Un Entre Rios cuyo gobernante no puede salir a campania no
			#     puede pelear la guerra que acaba de declarar, y en un anio este hombre tiene que
			#     ganar Caseros.
			#     Esta linea se escribio una vez y se perdio en silencio: la edicion que la agregaba
			#     no encontro el texto, porque el bloque del ejercito ya habia cambiado lo de
			#     alrededor. Aca esta ahora.
			#     Y EL ROL VA PRIMERO, que es la correccion del 20/9/2026 (Codex). add_commander_rank
			#     le sube el rango a un general; a un hombre que no es general no lo hace general. El
			#     Urquiza de vanilla no tiene is_general en su template
			#     (common/character_templates/country_arg.txt), asi que la linea de arriba sola le
			#     daba rango a nadie y el gobernante de Entre Rios seguia sin poder salir al campo.
			#     Vanilla hace las dos en este orden
			#     (events/agitators_events/historic_agitator_events.txt:1472-1475).
			#     / AND THE ROLE COMES FIRST: add_commander_rank promotes a general, it does not make
			#     one, and vanilla's Urquiza is not a general.
			add_character_role = general
			add_commander_rank = 2
		}
	}
	else = {
		# EN/ES: y el Urquiza de respaldo tambien sale general, que es la misma correccion: nacia sin
		#     rol y sin rango, o sea un gobernante que no podia mandar la guerra que acababa de
		#     declarar / the fallback Urquiza is made a general too, for the same reason
		c:ENR ?= {
			create_character = {
				template = ARG_Justo_Jose_de_Urquiza
				ruler = yes
				save_scope_as = gg_urquiza_nuevo
			}
		}
		if = {
			limit = { exists = scope:gg_urquiza_nuevo }
			scope:gg_urquiza_nuevo = {
				add_character_role = general
				add_commander_rank = 2
			}
		}
	}
}

# EN: THE EMPTYING. Called right after create_country and before anybody is brought in: every
#     character the clone brought along goes into exile. It is deliberately blunt -- no exceptions,
#     no list -- because any exception is a place where a clone can hide. A country with no
#     characters is a normal state for the engine: it generates the interest-group leaders it needs.
# ES: EL VACIADO. Se llama justo despues de create_country y antes de traer a nadie: todo personaje
#     que trajo el clonado se va al exilio. Es deliberadamente bruto -- sin excepciones, sin lista --
#     porque toda excepcion es un lugar donde un clon puede esconderse. Un pais sin personajes es un
#     estado normal para el motor: genera los lideres de grupo que necesite.
gg_argentina_new_country_people = {
	c:$TAG$ ?= {
		every_scope_character = {
			# EN: THE CLONES ARE KILLED, NOT EXILED, and the correction is dated 20 September 2026,
			#     from Codex's review. This used to call exile_character_with_role_cleanup, and the
			#     comment here claimed no clone could survive it. Read vanilla and the claim falls
			#     apart: common/scripted_effects/00_scripted_effects.txt:720-729 is three lines long
			#     and it is exile_character = yes, unassign_from_formation, and
			#     replace_character_roles = { add = { agitator } remove_all = yes }. Nothing dies.
			#     The clone leaves the country's roster and lands in the EXILE POOL, alive, carrying
			#     the same name and the same portrait, and from there any country can invite it back
			#     or it can surface as an agitator. Three births times a full Argentine roster is
			#     some thirty ghosts, and one of them is named Juan Manuel de Rosas.
			#     hidden = yes because nobody died: these people were never born. Vanilla uses the
			#     same form when it needs a silent death (events/brazil/paraguay.txt:292).
			# ES: LOS CLONES SE MATAN, NO SE EXILIAN, y la correccion es del 20/9/2026, de la revision
			#     de Codex. Esto llamaba a exile_character_with_role_cleanup y el comentario de aca
			#     afirmaba que ningun clon podia sobrevivirlo. Se lee vanilla y la afirmacion se cae:
			#     common/scripted_effects/00_scripted_effects.txt:720-729 tiene tres lineas y son
			#     exile_character = yes, unassign_from_formation y replace_character_roles con el rol
			#     de agitador. No muere nadie.
			#     El clon sale del plantel del pais y cae en la BOLSA DE EXILIADOS, vivo, con el mismo
			#     nombre y el mismo retrato, y desde ahi cualquier pais lo puede invitar o puede
			#     aparecer de agitador. Tres nacimientos por un plantel argentino entero son unos
			#     treinta fantasmas, y uno se llama Juan Manuel de Rosas.
			#     hidden = yes porque no murio nadie: esta gente nunca nacio. Vanilla usa la misma
			#     forma cuando necesita una muerte silenciosa (events/brazil/paraguay.txt:292).
			kill_character = {
				hidden = yes
			}
		}
		# EN/ES: y la delegacion, que desde aca se mira del otro lado / and the delegation, seen from
		#     the other side from here on
		if = {
			limit = { NOT = { has_journal_entry = je_gg_delegation } }
			add_contextless_journal_entry = je_gg_delegation
		}
	}
}

# EN: THE WAR THE TEXT PROMISES. Every one of these three events tells the player a province has
#     disavowed Buenos Aires and, in the Corrientes case, declared war outright -- and until now not
#     one of them opened anything. The three countries seceded in peace and could sit next to
#     Argentina for sixteen years. This is the play Rosas opens to bring them back: annexation, which
#     is what he actually did to Corrientes after Pago Largo and to the Coalition after Famailla.
#     It runs from ARGENTINA's option, so Rosas is the one who opens it -- the province did not
#     invade anybody, it stopped obeying.
# ES: LA GUERRA QUE EL TEXTO PROMETE. Cada uno de estos tres eventos le dice al jugador que una
#     provincia desconocio a Buenos Aires y, en el caso de Corrientes, que le declaro la guerra --
#     y hasta ahora ninguno abria nada. Los tres paises se separaban en paz y podian convivir con la
#     Argentina dieciseis anios. Esta es la jugada que abre Rosas para traerlos de vuelta: anexion,
#     que es lo que hizo de verdad con Corrientes despues de Pago Largo y con la Coalicion despues de
#     Famailla. Corre desde la opcion de la ARGENTINA, asi que la abre Rosas: la provincia no invadio
#     a nadie, dejo de obedecer.
# -------------------------------------------------------------------------------------------------
gg_argentina_open_war = {
	if = {
		limit = {
			exists = c:$TAG$
			c:ARG ?= this
		}
		create_diplomatic_play = {
			name = gg_argentina_play_$TAG$
			target_country = c:$TAG$
			type = dp_annex_war
			add_war_goal = {
				holder = c:ARG
				target_country = c:$TAG$
				type = annex_country
			}
		}
	}
}

# EN: CORRIENTES RISES AGAIN. Corrientes fell and came back twice, and a mod that only lets it be
#     born once is telling half of what happened: Pago Largo (31/3/1839) put a federal governor in
#     the city, Caa Guazu (28/11/1841) gave the province back to its own men, Arroyo Grande
#     (6/12/1842) lost it again, and the Madariaga brothers took it back in April 1843.
#     This is the one thing the interior campaign was missing. Rosas' armies are far stronger than a
#     single province, so in almost every game Corrientes is annexed within two years of 1839 -- and
#     with it went Paz and the Madariaga, three men who had a template and no way of ever existing.
#     WHY IT IS ITS OWN EFFECT and not gg_argentina_create_corrientes: the birth of 1839 puts Beron
#     de Astrada in the chair and hands Ferre the river programme. Beron died at Pago Largo twenty
#     five days later. A rebirth that raised him again would be a ghost governing.
#     The ruler is a parameter because each return had a different man at its head.
# ES: CORRIENTES VUELVE A LEVANTARSE. Corrientes cayo y volvio dos veces, y un mod que solo la deja
#     nacer una vez cuenta la mitad de lo que paso: Pago Largo (31/3/1839) puso un gobernador federal
#     en la ciudad, Caa Guazu (28/11/1841) le devolvio la provincia a los suyos, Arroyo Grande
#     (6/12/1842) la volvio a perder, y los hermanos Madariaga la recuperaron en abril de 1843.
#     Es lo unico que le faltaba a la campania del interior. Los ejercitos de Rosas son muchisimo mas
#     fuertes que una provincia sola, asi que en casi toda partida Corrientes queda anexada antes de
#     dos anios de 1839 -- y con ella se iban Paz y los Madariaga, tres hombres que tenian template y
#     ninguna manera de existir jamas.
#     POR QUE ES SU PROPIO EFECTO y no gg_argentina_create_corrientes: el nacimiento de 1839 sienta a
#     Beron de Astrada y le da a Ferre el programa fluvial. Beron murio en Pago Largo veinticinco
#     dias despues. Un renacimiento que lo levantara otra vez seria un fantasma gobernando.
#     El gobernante es un parametro porque cada vuelta tuvo un hombre distinto a la cabeza.
# SOURCE / FUENTE: docs/guerra-grande-argentina/historia-argentina.md
# -------------------------------------------------------------------------------------------------
gg_argentina_revive_corrientes = {
	create_country = {
		tag = CRR
		origin = this
		state = s:STATE_CORRIENTES.region_state:ARG
		on_created = {
			set_variable = gg_arg_corrientes_seat
		}
	}
	if = {
		limit = { exists = s:STATE_MISIONES.region_state:ARG }
		s:STATE_MISIONES.region_state:ARG = { set_state_owner = c:CRR }
	}
	gg_argentina_new_country_people = {
		TAG = CRR
	}
	c:CRR ?= {
		set_capital = STATE_CORRIENTES
		create_character = {
			template = $RULER$
			ruler = yes
		}
	}
	# EN: the delegation is withdrawn again -- but ONLY if the country is actually there. The effect
	#     is guarded by its own mark, so it cannot charge twice for the same absence; what this extra
	#     test buys is the case nobody can verify from a text editor: re-creating a tag that already
	#     lived and died. If the engine refuses it, everything below is a no-op and the event is only
	#     news -- but an ungated charge would still have taken twelve points off Rosas for a province
	#     that never came back. A bar must never disagree with the map.
	# ES: la delegacion se retira otra vez -- pero SOLO si el pais esta de verdad. El efecto esta
	#     guardado por su propia marca, asi que no cobra dos veces la misma ausencia; lo que compra
	#     este chequeo de mas es el caso que no se puede verificar desde un editor de texto: volver a
	#     crear un tag que ya vivio y murio. Si el motor no lo permite, todo lo de abajo no hace nada y
	#     el evento es solo una noticia -- pero un cobro sin guarda igual le habria sacado doce puntos
	#     a Rosas por una provincia que nunca volvio. La barra no puede discrepar con el mapa.
	if = {
		limit = { exists = c:CRR }
		gg_delegation_revoked = { KEY = corrientes COUNT = -1 POINTS = -12 }
	}
