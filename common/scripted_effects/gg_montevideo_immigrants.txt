# EN: 25/9/2026 (Juan: the immigrants arrive by events, as soldiers, with their nationalities; AUD-MVD-POPS) -- THE
#     PEOPLE WHO FILLED MONTEVIDEO. The war modifiers (static_modifiers/gg_war_demography.txt) only move births,
#     deaths and migration pull; with 8 arable land after the partition the engine sends Montevideo no mass
#     migration, so the Europeans and the Argentine emigres are created here, as pops of their own culture, when
#     the dated immigration events (events/gg_immigration.txt) and the legions (events/guerra_grande_contingents.txt,
#     the two legion buttons) bring them. Only in a Montevideo state that the Republic -- before the split -- or the
#     Defensa holds (tag URU): if the Cerrito, Rosas or anyone else holds the city, nobody lands and nothing is created.
#     Soldiers are soldiers pops: casualties shrink them like any other soldiers, which is what happened (the French
#     Legion fell from more than 3,000 to 1,134 by March 1850).
#
#     SIZES. Same scale as the mod's own 1836 population (common/history/pops/zz_guerra_grande_pops.txt): the five
#     Oriental states start with 192,610 against the 128,371 estimated for 1835 (Etchechury 2017, n. 31), so every
#     figure from the sources is multiplied by 1.5 and rounded.
#       padron of Montevideo, October 1843 (Andres Lamas): 31,189 inhabitants -- 5,324 French, 4,205 Italians,
#         3,406 Spaniards, 2,553 Argentines, 11,431 Orientals (Etchechury 2017, n. 32)
#       more than 33,000 European immigrants landed 1835-1842 (Etchechury 2017, n. 31)
#       French Legion: 2,904 men in May 1843 (docs/tropas-iniciales-2026-09-22.md, the sizing of gg_contingent.4),
#         a Basque battalion of 400-600 inside it from the start (Etchechury 2017, n. 59 and 61; 500 used), "more
#         than 3,000" at its height (n. 61)
#       Italian Legion: 500-700 men, about 700 at its best (Etchechury 2017, n. 63 and 68)
#       the resident foreigners who formed these militias were "artesanos, tenderos, comerciantes y jornaleros"
#         (Etchechury 2017, on militias of resident foreigners in Latin America): civilians come as laborers
#     The mod's 1836 Montevideo already holds 4,500 French and 4,500 Italians (3,000 and 3,000 at source scale), so
#     what the events add is what the 1843 padron has on top of that: the French through their legion, the Italians
#     through theirs and the 1842 ships, the Spaniards (none at start) and the Argentines through the two waves.
# ES: LA GENTE QUE LLENO MONTEVIDEO. Los modificadores de guerra solo mueven natalidad, mortalidad y atraccion; con 8
#     de tierra cultivable el motor no le manda migracion masiva, asi que los europeos y los emigrados argentinos se
#     crean aca, como pops de su cultura, cuando los traen los eventos de inmigracion fechados y las legiones. Solo en
#     un Montevideo de la Republica o de la Defensa (tag URU): si la ciudad es del Cerrito o de cualquier otro, no
#     desembarca nadie. Los soldados son pops de soldados y se achican con las bajas, como paso.
#     TAMAÑOS: la escala de la poblacion de 1836 del mod (192.610 contra 128.371 en 1835), o sea las cifras de las
#     fuentes por 1,5; lo que se agrega es lo que el padron de 1843 tiene de mas sobre la poblacion inicial.
# -------------------------------------------------------------------------------------------------

# EN: one pop in Montevideo, if the Republic or the Defensa holds it. Any scope. $TYPE$ is a pop type (soldiers,
#     laborers, clerks), $CULTURE$ a culture key; all the immigrants of these years were Catholic.
# ES: un pop en Montevideo, si la tiene la Republica o la Defensa. Cualquier scope.
gg_mvd_create_pop = {
	s:STATE_MONTEVIDEO ?= {
		random_scope_state = {
			limit = { gg_state_held_by_uru = yes }
			debug_log = "GG_EF|[TimeKeeper.GetCurrentDate.GetString]|gg_mvd_create_pop| $CULTURE$ $TYPE$ $SIZE$" # GG_TRAZA
			create_pop = {
				pop_type = $TYPE$
				culture = $CULTURE$
				religion = catholic
				size = $SIZE$
			}
		}
	}
}

# EN: the French Legion takes up arms (gg_contingent.4.a, or the button): 2,904 men x 1.5 -- 2,400 French and the
#     500 Basques of Brie de Laustan's battalion. If the legion is refused (gg_contingent.4.b), the same men stay in
#     the city as what they were, artisans and day labourers: the padron of October 1843 counts them either way.
# ES: la Legion Francesa toma las armas: 2.904 hombres por 1,5, 2.400 franceses y los 500 vascos de Brie de Laustan.
#     Si se la niega, los mismos hombres se quedan en la ciudad como lo que eran: el padron los cuenta igual.
gg_mvd_french_legion_men = {
	custom_tooltip = {
		text = gg_mvd_french_legion_men_tt
		gg_mvd_create_pop = { CULTURE = french TYPE = soldiers SIZE = 3600 }
		gg_mvd_create_pop = { CULTURE = basque TYPE = soldiers SIZE = 750 }
	}
}
gg_mvd_french_legion_refused_men = {
	custom_tooltip = {
		text = gg_mvd_french_legion_refused_men_tt
		gg_mvd_create_pop = { CULTURE = french TYPE = laborers SIZE = 3600 }
		gg_mvd_create_pop = { CULTURE = basque TYPE = laborers SIZE = 750 }
	}
}
