# EN: THE ARMIES AT THE SPLIT (22/9/2026, decided with Juan, docs/tropas-iniciales-2026-09-22.md).
#     Replaces the fixed armies both options of guerra_grande.3 used to create. Two things the
#     old code did not know, verified in Juan's saves of 1/1/1843 and 1/7/1843:
#     - Units belong to a barracks, and they follow it when the state changes hands. Whoever holds
#       Montevideo takes the old Republic's battalions there, in either option.
#     - A battalion with no men yet does not survive that change of owner. With .3.b the Ejercito
#       de Operaciones (raised in December 1842, still empty) and the 1836 cuirassiers vanished.
#     So nothing is fixed any more: two days after the split, once the engine has moved or
#     dropped what it moves or drops, each government is topped up arm by arm to its sourced
#     target. What was inherited counts; what is missing is raised. Nothing can be removed: there
#     is no script effect that disbands a formation (checked in the playset mods, the Workshop,
#     the expansions and the game's own strings), so an inheritance above the target stays.
#     New battalions are born with no men and fill over the following months; that is the
#     engine, and no effect sets manpower.
# ES: LOS EJERCITOS EN EL CORTE. Reemplaza los ejercitos fijos que creaban las dos opciones. Dos
#     cosas que el codigo viejo no sabia, verificadas en las saves de Juan:
#     - Las unidades son de un cuartel y lo siguen cuando el estado cambia de dueño. Quien tiene
#       Montevideo se queda con los batallones de la vieja Republica ahi, en las dos opciones.
#     - Un batallon todavia sin hombres no sobrevive ese cambio de dueño. Con .3.b desaparecieron el
#       Ejercito de Operaciones (levantado en diciembre de 1842, vacio) y los coraceros de 1836.
#     Entonces ya nada es fijo: dos dias despues del corte, cuando el motor ya movio o descarto lo
#     suyo, cada gobierno se completa arma por arma hasta su objetivo con fuente. Lo heredado cuenta;
#     lo que falta se levanta. No se puede quitar nada: no hay efecto que disuelva formaciones, asi
#     que una herencia por encima del objetivo queda. Los batallones nuevos nacen sin hombres y se
#     llenan en los meses siguientes; es el motor.

	debug_log = "GG_EF|[TimeKeeper.GetCurrentDate.GetString]|gg_troops_cer_recruit_states|" # GG_TRAZA
	random_scope_state = { limit = { state_region = s:STATE_SAN_JOSE } save_scope_as = gg_cer_rec_home }
	if = {
		limit = { any_scope_state = { state_region = s:STATE_PAYSANDU } }
		random_scope_state = { limit = { state_region = s:STATE_PAYSANDU } save_scope_as = gg_cer_rec_horse }
	}
	else = { scope:gg_cer_rec_home ?= { save_scope_as = gg_cer_rec_horse } }
	if = {
		limit = { any_scope_state = { state_region = s:STATE_BANDA_ORIENTAL } }
		random_scope_state = { limit = { state_region = s:STATE_BANDA_ORIENTAL } save_scope_as = gg_cer_rec_irregular }
	}
	else = { scope:gg_cer_rec_home ?= { save_scope_as = gg_cer_rec_irregular } }
	if = {
		limit = { any_scope_state = { state_region = s:STATE_MALDONADO } }
		random_scope_state = { limit = { state_region = s:STATE_MALDONADO } save_scope_as = gg_cer_rec_guns }
	}
	else = { scope:gg_cer_rec_home ?= { save_scope_as = gg_cer_rec_guns } }
