# EN: The Guerra Grande systems (docs/guerra-grande-flujo/to-be.md, C19, FG-1, FG-2).
#     T3a: variables and their single writers only -- nothing reads them yet. Every change to a
#     patron, to the Defensa's line or to the Cerrito's balance goes through one of these
#     effects, so the invariant check (I14) can prove nobody writes them anywhere else.
#     Starting values are provisional until the balance pass (T10).
# ES: Los sistemas de la Guerra Grande (docs/guerra-grande-flujo/to-be.md, C19, FG-1, FG-2).
#     T3a: solo las variables y quien las escribe -- todavia nadie las lee. Todo cambio a un
#     padrino, a la linea de la Defensa o a la balanza del Cerrito pasa por uno de estos
#     efectos, asi el chequeo de invariantes (I14) puede probar que nadie las escribe en otro
#     lado. Los valores iniciales son provisorios hasta la pasada de balance (T10).

# EN: Country scope. Clear the previous result so a landless country cannot reuse another HQ.
#     Keep the capital only while owned; otherwise use one of this country's states.
# ES: Scope de pais. Limpia el resultado anterior para no prestarle otro cuartel a un pais sin tierra.
#     Conserva la capital solo si es propia; si no, usa cualquiera de los estados del pais.
gg_select_formation_hq_state = {
	clear_saved_scope = gg_formation_hq_state
	if = {
		limit = {
			exists = capital
			capital = { owner = prev }
		}
		capital = { save_scope_as = gg_formation_hq_state }
	}
	else = {
		random_scope_state = {
			limit = { owner = prev }
			save_scope_as = gg_formation_hq_state
		}
	}
}

# EN: usage: gg_score_blanco = { AMOUNT = 2 }. AMOUNT must be a positive literal: the colorado
#     side's tooltip key is built from it, so a negative number or a named value would not resolve.
#     To take score away from one side, give it to the other. Moves the score, and the journal bar if the
#     journal already exists (before Carpinteria it does not; .1 syncs the bar when it opens).
# ES: uso: gg_score_blanco = { AMOUNT = 2 }. AMOUNT tiene que ser un numero positivo escrito tal
#     cual: la clave del tooltip se arma con el. Para restarle a un bando, se le suma
#     al otro. Mueve el puntaje, y la barra si el journal ya existe
#     (antes de Carpinteria no existe; .1 sincroniza la barra al abrirlo).
gg_score_blanco = {
	# EN/ES: shown to the player; global variables have no tooltip of their own / se muestra al jugador
	custom_tooltip = {
		text = gg_tt_score_blanco_$AMOUNT$
		change_global_variable = { name = guerra_grande_blanco_score add = $AMOUNT$ }
		change_global_variable = { name = gg_src_decisions_blanco add = $AMOUNT$ }
		je:je_guerra_grande ?= {
			set_bar_progress = { name = guerra_grande_war_score_bar value = gg_war_score_bar_value }
		}
	}
}

# EN: usage: gg_patron_change = { PATRON = francia DELTA = -15 }
#     PATRON is one of rosas, francia, britania, brasil, urquiza. The result is kept in 0-100.
# ES: uso: gg_patron_change = { PATRON = francia DELTA = -15 }
#     PATRON es rosas, francia, britania, brasil o urquiza. El resultado queda entre 0 y 100.
gg_patron_change = {
	# EN/ES: shown to the player; global variables have no tooltip of their own / se muestra al jugador
	custom_tooltip = {
		text = gg_tt_patron_$PATRON$_$DELTA$
		change_global_variable = { name = gg_patron_$PATRON$ add = $DELTA$ }
		if = {
			limit = { global_var:gg_patron_$PATRON$ > 100 }
			set_global_variable = { name = gg_patron_$PATRON$ value = 100 }
		}
		else_if = {
			limit = { global_var:gg_patron_$PATRON$ < 0 }
			set_global_variable = { name = gg_patron_$PATRON$ value = 0 }
		}
		debug_log = "[TimeKeeper.GetCurrentDate.GetString]: GG_PATRON $PATRON$ $DELTA$"
	}
}

# EN: T6, the Defensa's law of 1842, dispatched once (Codex review 2026-09-19). Three places could
#     schedule it -- the dated dispatcher of 12 December, Arroyo Grande six days later, and the
#     partition's backstop -- and all three asked the same question: "is it settled yet?". A popup
#     waits 1825 days for an answer, so an unanswered law was not settled and a second copy could be
#     scheduled on top of the first. Dispatched and settled are two different things now.
# ES: T6, la ley de la Defensa de 1842, despachada una sola vez. Tres lugares podian agendarla -- el
#     despachador del 12 de diciembre, Arroyo Grande seis dias despues y el respaldo de la particion
#     -- y los tres preguntaban lo mismo: "ya esta resuelta?". Un popup espera 1825 dias una
#     respuesta, asi que una ley sin contestar no estaba resuelta y se podia agendar una segunda
#     copia encima de la primera. Despachada y resuelta ya no son lo mismo.
gg_abolition_dispatch = {
	if = {
		limit = {
			NOT = { has_global_variable = gg_abolition_dispatched }
			# EN/ES: the law lives on the Defensa, not on whoever calls this / la ley vive en la
			#     Defensa, no en quien llame a este efecto
			c:URU ?= { NOT = { has_variable = guerra_grande_abolition_settled } }
		}
		set_global_variable = gg_abolition_dispatched
		c:URU ?= {
			trigger_event = { id = gg_abolition.2 days = $DAYS$ popup = yes }
		}
	}
}

# EN: T1/T9, the closing of the war, in one idempotent place (Codex review 2026-09-19). It used to
#     live inside on_complete_all_involved only, and the journal has two ways out: complete and fail.
#     A foreign power holding Montevideo is a fail, so that game closed the war without handing the
#     final event to anybody -- while the mirror case (a third country eating the Cerrito) did get
#     one. Both hooks call this now, the mark makes it run once, and it always names a recipient.
# ES: T1/T9, el cierre de la guerra, en un solo lugar y una sola vez. Vivia dentro de
#     on_complete_all_involved nada mas, y el journal tiene dos salidas: complete y fail. Que una
#     potencia extranjera se quede con Montevideo es un fail, asi que esa partida cerraba la guerra
#     sin entregarle el evento final a nadie, mientras que el caso espejo (un tercero se come al
#     Cerrito) si lo recibia. Ahora lo llaman las dos salidas, la marca hace que corra una vez, y
#     siempre hay destinatario.
gg_war_closing_dispatch = {
	if = {
		limit = {
			NOT = { has_global_variable = gg_peace_settled }
			# EN/ES: Codex review 2026-09-19 -- with both governments gone there is nobody to hand the
			#     terms to, and marking the peace as pending would leave a menu waiting forever. The
			#     journal still closes: this only decides who signs. / sin los dos gobiernos no hay a
			#     quien entregarle el pliego, y marcar la paz como pendiente dejaba un menu esperando
			#     para siempre. El journal cierra igual: esto solo decide quien firma.
			OR = {
				exists = c:CER
				exists = c:URU
			}
		}
		set_global_variable = gg_peace_settled
		set_global_variable = gg_victory_pending
		# EN: a third country took the war away from both (Codex review 2026-09-19, second pass: the
		#     simplified test lost the mirror case -- a foreign power eating the Cerrito while the
		#     Defensa still held Montevideo was read as the Defensa winning the war on its own).
		#     Three ways: nobody oriental holds the capital, or one government is gone and the other
		#     does not hold the ground that government lost.
		# ES: un tercero les saco la guerra a los dos. La prueba simplificada perdia el caso espejo:
		#     una potencia extranjera comiendose al Cerrito con la Defensa todavia en Montevideo se
		#     leia como que la Defensa habia ganado la guerra sola. Tres formas: que ningun oriental
		#     tenga la capital, o que falte un gobierno y el otro no tenga el suelo que ese perdio.
		if = {
			limit = {
				OR = {
					NOR = {
						c:URU ?= { any_scope_state = { state_region = s:STATE_MONTEVIDEO } }
						c:CER ?= { any_scope_state = { state_region = s:STATE_MONTEVIDEO } }
					}
					AND = {
						NOT = { exists = c:CER }
						c:URU ?= { NOT = { any_scope_state = { state_region = s:STATE_SAN_JOSE } } }
					}
					AND = {
						NOT = { exists = c:URU }
						c:CER ?= { NOT = { any_scope_state = { state_region = s:STATE_MONTEVIDEO } } }
					}
				}
			}
			set_global_variable = gg_victory_third_party
			# EN/ES: nobody oriental won this one, so the occupation marks must not say otherwise
			#     / no gano ningun oriental, asi que las marcas de ocupacion no pueden decir otra cosa
			set_global_variable = { name = gg_cerrito_overrun value = 0 }
			set_global_variable = { name = gg_defensa_overrun value = 0 }
		}
		else_if = {
			limit = {
				NOR = {
					gg_cerrito_won_militarily = yes
					gg_defensa_won_militarily = yes
				}
			}
			set_global_variable = gg_victory_timeout
		}
		# EN/ES: who writes the terms / quien escribe el pliego
		# EN: Codex review 2026-09-19, third pass -- a war that a third country ended does not have an
		#     oriental winner, and asking the military triggers for one produced answers like "the
		#     Cerrito won" while a foreign flag flew over Montevideo. There the paper goes to whoever
		#     is left standing, the Defensa first because the Republic's tag is hers, and gg_peace.5
		#     already has its own text for this ending.
		# ES: una guerra que termino un tercero no tiene ganador oriental, y preguntarle a los triggers
		#     militares daba respuestas como "gano el Cerrito" con una bandera extranjera sobre
		#     Montevideo. Ahi el papel es del que haya quedado en pie, la Defensa primero porque el tag
		#     de la Republica es suyo, y gg_peace.5 ya tiene su texto para este final.
		if = {
			limit = {
				has_global_variable = gg_victory_third_party
				exists = c:URU
			}
			random_country = {
				limit = { has_variable = guerra_grande_defensa_government }
				trigger_event = { id = gg_peace.5 days = 1 popup = yes }
			}
		}
		else_if = {
			limit = { has_global_variable = gg_victory_third_party }
			random_country = {
				limit = { has_variable = guerra_grande_cerrito_government }
				trigger_event = { id = gg_peace.5 days = 1 popup = yes }
			}
		}
		else_if = {
			limit = { gg_cerrito_won_militarily = yes }
			random_country = {
				limit = { has_variable = guerra_grande_cerrito_government }
				trigger_event = { id = gg_peace.5 days = 1 popup = yes }
			}
		}
		else_if = {
			limit = { gg_defensa_won_militarily = yes }
			random_country = {
				limit = { has_variable = guerra_grande_defensa_government }
				trigger_event = { id = gg_peace.5 days = 1 popup = yes }
			}
		}
		# EN/ES: no winner (the 1860 cut, or a stalemate): the paper is read by whoever is ahead on the
		#     same number the bar shows, and if nobody is ahead, by the Defensa / sin ganador (el corte
		#     de 1860 o un empate): lee el papel el que va arriba en el mismo numero que muestra la
		#     barra, y si no hay nadie arriba, la Defensa
		else_if = {
			limit = {
				exists = c:CER
				gg_war_balance_blanco > 0
			}
			random_country = {
				limit = { has_variable = guerra_grande_cerrito_government }
				trigger_event = { id = gg_peace.5 days = 1 popup = yes }
			}
		}
		else_if = {
			limit = { exists = c:URU }
			random_country = {
				limit = { has_variable = guerra_grande_defensa_government }
				trigger_event = { id = gg_peace.5 days = 1 popup = yes }
			}
		}
		else_if = {
			limit = { exists = c:CER }
			random_country = {
				limit = { has_variable = guerra_grande_cerrito_government }
				trigger_event = { id = gg_peace.5 days = 1 popup = yes }
			}
		}
	}
	# EN: Codex review 2026-09-19 -- the postwar lives OUTSIDE the "no peace signed" guard, and it is
	#     not started here when there is a victory menu on the table: gg_peace.5 starts it from its
	#     own options. Otherwise the postwar chose its branch (and changed the Cerrito's tag, which
	#     can eat the pending event) before the player had answered the menu.
	# ES: la posguerra va AFUERA de la guarda de "nadie firmo la paz", y no arranca aca cuando hay un
	#     menu de victoria sobre la mesa: lo arranca gg_peace.5 desde sus propias opciones. Si no, la
	#     posguerra elegia rama -- y le cambiaba el tag al Cerrito, lo que puede comerse el evento
	#     pendiente -- antes de que el jugador contestara.
	if = {
		limit = { NOT = { has_global_variable = gg_victory_pending } }
		gg_postwar_start = yes
	}
}

# EN: T6/T7, the dated calendar's relay (events/guerra_grande_calendar.txt has the whole reasoning).
#     Hands a dated event to the government that owns it. If the country has not split yet the relay
#     waits a month and tries again, so a late partition does not swallow what was dated before it.
#     The mark makes it fire once, because two copies of every relay are scheduled (Rosas and the
#     Republic) against the chance that a tag change at the partition drops the queued events.
# ES: T6/T7, el relevo del calendario fechado (el razonamiento entero esta en
#     events/guerra_grande_calendar.txt). Le entrega un evento fechado al gobierno que le toca. Si el
#     pais todavia no se partio, el relevo espera un mes y reintenta, asi una particion tardia no se
#     come lo fechado antes. La marca hace que salga una sola vez, porque de cada relevo hay dos
#     copias agendadas (Rosas y la Republica) por si el cambio de tag de la particion se lleva puestos
#     los eventos agendados.
gg_cal_fire = {
	if = {
		limit = { NOT = { has_global_variable = $DONE$ } }
		if = {
			# EN: Only the recipient's immediate acknowledges delivery. Its trigger can reject
			#     this attempt even when the country exists; retry independently below.
			# ES: Solo el immediate del destinatario confirma la entrega. Su trigger puede
			#     rechazar el intento aunque exista el pais; el reintento de abajo es independiente.
			limit = {
				has_global_variable = guerra_grande_split_done
				any_country = { has_variable = $SIDE$ }
			}
			random_country = {
				limit = { has_variable = $SIDE$ }
				trigger_event = { id = $EVENT$ days = 0 popup = yes }
			}
		}
		if = {
			limit = {
				year < 1856
				NOT = { has_global_variable = $DONE$ }
			}
			trigger_event = { id = $RETRY$ days = 30 }
		}
	}
}

# ES: LA PRESIDENCIA, POR CARRIL FIJO. La jefatura de Estado sigue la historia y no la urna: una
#     eleccion en mitad de la guerra le daba la presidencia al politico de partido que ganara la
#     votacion, en los dos caminos. Fuentes (Wikipedia ES) en el parrafo de arriba.
gg_ruler_set = {
	if = {
		limit = { any_scope_character = { has_template = $TEMPLATE$ } }
		random_scope_character = {
			limit = { has_template = $TEMPLATE$ }
			set_character_as_ruler = yes
		}
	}
	# EN: AND IF HE IS ALIVE SOMEWHERE ELSE, HE IS FETCHED, NOT COPIED. Added 20/9/2026. This used to
	#     go straight from «not here» to create_character, and the case that breaks is the one the
	#     whole mod turns on: Oribe leaves Montevideo in October 1838 for Buenos Aires, and four years
	#     later the Cerrito is founded on his army. The Cerrito did not have him -- he was in
	#     Argentina -- so it made a second Manuel Oribe, and the game had two of the same man, one
	#     besieging Montevideo and one in Rosas' government.
	#     A ruler who exists is moved. Only a ruler who exists nowhere is created.
	# ES: Y SI ESTA VIVO EN OTRA PARTE, SE LO VA A BUSCAR, NO SE LO COPIA. Agregado el 20/9/2026. Esto
	#     saltaba de «no esta aca» directo a create_character, y el caso que lo rompe es aquel sobre el
	#     que gira el mod entero: Oribe se va de Montevideo en octubre de 1838 a Buenos Aires, y cuatro
	#     anios despues el Cerrito se funda sobre su ejercito. El Cerrito no lo tenia -- estaba en la
	#     Argentina -- asi que fabricaba un segundo Manuel Oribe, y el juego tenia dos del mismo
	#     hombre, uno sitiando Montevideo y otro en el gobierno de Rosas.
	#     Un gobernante que existe se muda. Solo se crea el que no existe en ninguna parte.
	else_if = {
		limit = {
			any_country = {
				any_scope_character = { has_template = $TEMPLATE$ }
			}
		}
		save_scope_as = gg_ruler_claimant
		random_country = {
			limit = {
				any_scope_character = { has_template = $TEMPLATE$ }
			}
			random_scope_character = {
				limit = { has_template = $TEMPLATE$ }
				transfer_character = scope:gg_ruler_claimant
			}
		}
		random_scope_character = {
			limit = { has_template = $TEMPLATE$ }
			set_character_as_ruler = yes
		}
	}
	else = {
		create_character = {
			template = $TEMPLATE$
			ruler = yes
		}
	}
}

# EN/ES: who should be sitting in the chair right now, in this country / quien deberia estar en el
#     sillon ahora mismo, en este pais
gg_president_historical = {
	if = {
		limit = { has_variable = guerra_grande_cerrito_government }
		gg_ruler_set = { TEMPLATE = URU_Manuel_Oribe }
	}
	else_if = {
		limit = {
			has_variable = guerra_grande_defensa_government
			OR = {
				NOT = { has_global_variable = gg_peace_settled }
				has_global_variable = gg_president_railroad
			}
		}
		gg_ruler_set = { TEMPLATE = URU_joaquin_suarez }
	}
	else_if = {
		limit = {
			has_variable = guerra_grande_blanco_path
			NOT = { has_global_variable = gg_rivera_presidency }
		}
		gg_ruler_set = { TEMPLATE = URU_Manuel_Oribe }
	}
	else_if = {
		limit = {
			has_global_variable = gg_rivera_presidency
			year >= 1839
		}
		gg_ruler_set = { TEMPLATE = URU_Fructuoso_Rivera }
	}
	else_if = {
		limit = { has_global_variable = gg_rivera_presidency }
		gg_ruler_set = { TEMPLATE = URU_gg_gabriel_antonio_pereira }
	}
}

# EN: fighting on after the arbiter declared this government beaten (playtest 2026-09-17): the
#     exhaustion counter restarts, the arbiter is shut for a year, and the decision costs what such
#     a decision costs.
# ES: seguir peleando despues de que el arbitro declaro agotado a este gobierno: el contador vuelve
#     a cero, el arbitro se cierra por un anio y la decision cuesta lo que cuesta.
gg_peace_fight_on = {
	remove_global_variable = gg_peace_offered
	set_global_variable = { name = gg_peace_cooldown days = 365 }
	if = {
		limit = { has_variable = guerra_grande_cerrito_government }
		set_global_variable = { name = gg_cerrito_exhausted value = 0 }
	}
	else = {
		set_global_variable = { name = gg_defensa_exhausted value = 0 }
	}
	every_scope_war = {
		limit = { gg_is_the_war = yes }
		add_war_war_support = { target = root value = -10 }
	}
	add_radicals = { value = small_radicals }
}

# -------------------------------------------------------------------------------------------------
# EN: THE ONLY WRITERS OF THE DELEGATION. Everything that moves it goes through here, the same way
#     every patron change goes through gg_patron_change, so the invariant check can prove nobody
#     writes it anywhere else.
#     DELTA is in internal points: 12 is one whole provincial delegation, 1 is one month of siege.
# ES: LOS UNICOS QUE ESCRIBEN LA DELEGACION. Todo lo que la mueve pasa por aca, igual que todo cambio
#     de padrino pasa por gg_patron_change, asi el chequeo de invariantes puede probar que nadie la
#     escribe en otro lado.
#     DELTA va en puntos internos: 12 es una delegacion provincial entera, 1 es un mes de sitio.
# -------------------------------------------------------------------------------------------------
gg_delegation_change = {
	# EN: THE POINTS ARE GONE AND THIS IS WHAT IS LEFT OF THEM. Until 20/9/2026 the delegation was a
	#     count of 156 -- thirteen provinces times twelve -- and this effect moved it and redrew a bar.
	#     The bar mixed the provinces with the monthly wear of the siege, so it fell while nothing had
	#     happened on the map, and Juan could not read it: «no se entiende un carajo». The provinces
	#     are now thirteen marks and the journal prints them one by one.
	#     The effect stays because thirteen call sites pass POINTS to it and because the rule of this
	#     mod is that no global changes in silence: what it keeps is the number nobody has to
	#     interpret -- how many provinces delegate -- which the list above it now shows one by one.
	#     There is no bar left to redraw.
	# ES: LOS PUNTOS SE FUERON Y ESTO ES LO QUE QUEDO DE ELLOS. Hasta el 20/9/2026 la delegacion era
	#     una cuenta de 156 -- trece provincias por doce -- y este efecto la movia y redibujaba una
	#     barra. La barra mezclaba las provincias con el desgaste mensual del sitio, asi que bajaba sin
	#     que hubiera pasado nada en el mapa, y Juan no podia leerla: «no se entiende un carajo». Las
	#     provincias ahora son trece marcas y el journal las imprime una por una.
	#     El efecto se queda porque trece lugares le pasan POINTS y porque la regla de este mod es que
	#     ninguna global cambia en silencio: lo que conserva es el numero que nadie tiene que
	#     interpretar --cuantas provincias delegan-- que la lista de arriba ahora muestra una por una.
	#     Ya no hay barra que redibujar.
	change_global_variable = {
		name = gg_delegation_points
		add = $DELTA$
	}
}

# EN/ES: a named province (or bloc) stops delegating, once and once only. COUNT y POINTS negativos.
# -------------------------------------------------------------------------------------------------
# EN: A CLAIM OPENED, AND A CLAIM ANSWERED. Written 20/9/2026, and the reason is Juan's, playing:
#     «los eventos de la previa son todos para corrientes! y no estan conectadas a la mecanica del
#     journal no entiendo que estas haciendo».
#     He was right twice. Of the seven build-up events, four were Corrientes' -- and not one of the
#     seven touched the Federal Pact at all. So the player spent three years answering petitions,
#     refusing demands and sending generals, and the panel that is supposed to be the state of the
#     Confederation did not move once until a province seceded in 1839. Decisions that leave no trace
#     on the only thing that shows the state of the thing they are about are not decisions.
#     A province now has three states, not two: it delegates, it delegates WITH A CLAIM OPEN against
#     Buenos Aires, or it has withdrawn the charge. Every build-up event opens or answers a claim, so
#     the panel is alive from 1836 and the player can watch the grievances pile up before anything
#     breaks. Withdrawing the charge closes the claim, because a province that has left has stopped
#     asking.
# ES: UN RECLAMO ABIERTO, Y UN RECLAMO CONTESTADO. Escrito el 20/9/2026, y la razon es de Juan,
#     jugando: «los eventos de la previa son todos para corrientes! y no estan conectadas a la
#     mecanica del journal no entiendo que estas haciendo».
#     Tenia razon dos veces. De los siete eventos de la previa, cuatro eran de Corrientes -- y
#     ninguno de los siete tocaba el Pacto Federal. Asi que el jugador se pasaba tres anios
#     contestando pliegos, negando reclamos y mandando generales, y el panel que representa el estado
#     de la Confederacion no se movia una sola vez hasta que una provincia se separaba en 1839. Las
#     decisiones que no dejan rastro en lo unico que muestra el estado de aquello de lo que tratan no
#     son decisiones.
#     Una provincia tiene ahora tres estados y no dos: delega, delega CON UN RECLAMO ABIERTO contra
#     Buenos Aires, o retiro el encargo. Cada evento de la previa abre o contesta un reclamo, asi que
#     el panel esta vivo desde 1836 y el jugador ve acumularse los agravios antes de que se rompa
#     nada. Retirar el encargo cierra el reclamo, porque una provincia que se fue dejo de pedir.
# -------------------------------------------------------------------------------------------------
gg_reclamo_abre = {
	if = {
		limit = {
			NOT = { has_global_variable = gg_reclamo_$KEY$ }
			# EN: A late answer to a five-year popup cannot reopen a claim for a province that has
			#     already withdrawn its delegation. ES: Una respuesta tardia a un popup de cinco
			#     anios no puede reabrir el reclamo de una provincia que ya retiro su delegacion.
			NOT = { has_global_variable = gg_delegation_gone_$KEY$ }
		}
		set_global_variable = gg_reclamo_$KEY$
		# EN/ES: no hay contador aparte: la lista del panel muestra CUALES, que es mejor que cuantos
		#     / no separate counter: the panel's list shows WHICH, which beats how many
	}
}

gg_reclamo_cierra = {
	if = {
		limit = { has_global_variable = gg_reclamo_$KEY$ }
		remove_global_variable = gg_reclamo_$KEY$
	}
}

gg_delegation_revoked = {
	if = {
		limit = { NOT = { has_global_variable = gg_delegation_gone_$KEY$ } }
		set_global_variable = gg_delegation_gone_$KEY$
		# EN/ES: y el reclamo se cierra: la que se fue dejo de pedir / a province that left stopped asking
		gg_reclamo_cierra = { KEY = $KEY$ }
		change_global_variable = {
			name = gg_delegating_provinces
			add = $COUNT$
		}
		gg_delegation_change = { DELTA = $POINTS$ }
	}
	# EN: AND THE COUNT THAT NEVER GOES BACK DOWN, added 20 September 2026 after Codex's integral
	#     review. The delegation bar is a photograph of today: a province that left and was taken
	#     back gives its twelve points back, and by February 1843 a Rosas who spent four years at war
	#     in the interior can be sitting on the same 156 points as a Rosas whom nobody ever defied.
	#     The balance of the interior was reading that photograph and calling both of them a clean
	#     victory. They are not the same thing, and this counter is what tells them apart: it only
	#     ever goes up, and the mark that guards it is the same one, so a province is counted once no
	#     matter how many times it is lost and retaken.
	#     It is deliberately outside the block above. That block is guarded by the mark and so is
	#     this, but keeping them apart makes it readable: up there is what the bar shows, down here is
	#     what the war cost.
	# ES: Y LA CUENTA QUE NO VUELVE A BAJAR, agregada el 20/9/2026 tras la revision integral de Codex.
	#     La barra de la delegacion es una foto de hoy: una provincia que se fue y fue recuperada
	#     devuelve sus doce puntos, y para febrero de 1843 un Rosas que se paso cuatro anios en guerra
	#     en el interior puede estar sentado sobre los mismos 156 puntos que un Rosas al que nadie
	#     desafio nunca. El balance del interior leia esa foto y a los dos les decia victoria limpia.
	#     No son lo mismo, y este contador es lo que los distingue: solo sube, y lo guarda la misma
	#     marca, asi que una provincia se cuenta una sola vez por mas veces que se pierda y se
	#     recupere.
	#     Esta a proposito afuera del bloque de arriba. Aquel lo guarda la marca y a este tambien,
	#     pero tenerlos separados se lee mejor: arriba esta lo que muestra la barra, aca abajo lo que
	#     costo la guerra.
	if = {
		limit = { NOT = { has_global_variable = gg_alzada_$KEY$ } }
		set_global_variable = gg_alzada_$KEY$
		change_global_variable = {
			name = gg_provincias_alzadas
			add = 1
		}
	}
}

# EN/ES: y vuelve a delegar, recuperada por las armas. COUNT y POINTS positivos.
gg_delegation_restored = {
	if = {
		limit = { has_global_variable = gg_delegation_gone_$KEY$ }
		remove_global_variable = gg_delegation_gone_$KEY$
		change_global_variable = {
			name = gg_delegating_provinces
			add = $COUNT$
		}
		gg_delegation_change = { DELTA = $POINTS$ }
	}
}
