# EN: 25/9/2026 (Juan, AUD-CASEROS-WAR) -- THE DAY OF CASEROS IS DECIDED BY THE WAR AS IT WAS FOUGHT. gg_caseros.10 reads
#     the engine's own facts of the war between Buenos Aires and Entre Rios into the gg_caseros_in_* globals (battles
#     lost, ground under the enemy, battalions under arms, war support) and these four values weigh them. Positive is
#     Urquiza's, negative Rosas's. The day goes to whoever leads by gg_caseros_decisive or more; closer than that is a
#     near-tie and only then fortune decides (gg_caseros.10). The Pact lab (tools/lab_balance/pacto.py) reads every
#     number of this file, and the tooltips gg_argentina.41.*_day_tt say the ones the player can move.
#       - battles: the share of the war's fighting (weighted by the men engaged) each side lost, from the engine
#         (size_weighted_lost_battles_fraction); a war whose battles all went one way is worth 40;
#       - ground: the weighted share of each country under the enemy (enemy_occupation, the engine's own measure), 30
#         for all of it; Buenos Aires in the enemy's hands 15, Rosas's Santa Fe 5, Entre Rios 15 the other way; and the
#         field Rosas chose: manoeuvring away from battle 10 for him, holding the city 5;
#       - numbers: each side's strength on the field, one against the other, 80 for all of it on one side (26/9/2026,
#         AUD-CASEROS-FORCES, below: Brazil's division counted in battalions, Buenos Aires's ranks coming apart a quarter off);
#       - spirit: each side's war support in bands of 25 (above 0, 25, 50, 75), 5 a band of difference.
# ES: LA JORNADA DE CASEROS LA DECIDE LA GUERRA COMO SE PELEO. gg_caseros.10 lee los hechos del motor (batallas perdidas,
#     suelo en manos enemigas, batallones en armas, apoyo a la guerra) y estos cuatro valores los pesan. Positivo es de
#     Urquiza, negativo de Rosas. Se lleva la jornada quien saca gg_caseros_decisive o mas; mas parejo que eso es un
#     empate y solo ahi decide la suerte. El laboratorio del Pacto lee cada numero de este archivo.
# SOURCE / FUENTE: docs/guerra-grande-argentina/historia-argentina.md, «Caseros» [D]: ~22.000-25.000 de Rosas contra al
#     menos 24.000 de Urquiza (3.500 brasilenos y 1.500 uruguayos) -- two armies of like size; the day was decided by the
#     Rosista army's disarray (Pacheco's resignation, the Santa Fe and Rosario defections), which is what the ground held
#     and the war support measure here. DESIGN / DISENO: the weights are game scale, tuned with the Pact lab.
# -------------------------------------------------------------------------------------------------

# EN/ES: the lead that decides the day without fortune / la ventaja que decide la jornada sin la suerte
gg_caseros_decisive = 10

# EN/ES: within a near-tie, from this lead the side ahead has fortune 70/30; below it, an even roll (gg_caseros.10)
#     / dentro del empate, desde esta ventaja el que va adelante tiene la suerte 70/30; debajo, una tirada pareja
gg_caseros_close = 5

# EN/ES: the battles of this war / las batallas de esta guerra
gg_caseros_day_battles = {
	value = global_var:gg_caseros_in_lost_arg
	subtract = global_var:gg_caseros_in_lost_enr
	multiply = 0.4
}

# EN/ES: the ground each side holds, and the field Rosas chose / el suelo que tiene cada lado y el campo que eligio Rosas
gg_caseros_day_ground = {
	value = global_var:gg_caseros_in_occ_arg
	subtract = global_var:gg_caseros_in_occ_enr
	multiply = 0.3
	if = { limit = { global_var:gg_caseros_in_ba = 1 } add = 15 }
	if = { limit = { global_var:gg_caseros_in_sf = 1 } add = 5 }
	if = { limit = { global_var:gg_caseros_in_er = 1 } add = -15 }
	if = { limit = { global_var:gg_caseros_choice ?= 2 } add = -10 }
	if = { limit = { global_var:gg_caseros_choice ?= 3 } add = -5 }
}

# EN: 26/9/2026 (Juan, AUD-CASEROS-FORCES) -- THE ARMIES AS THEY STAND DECIDE THE DAY, IN PROPORTION. The sweep on 832c5cb
#     (barrido_20260926-181706/-181726) fought no battle before Caseros in any war, so the day was the troops, the spirit and
#     the allies' flags only, and it came out a near-tie the dice decided even when one side doubled the other: traza_20260926-
#     181813 Urquiza 24 battalions against Rosas's 12 scored +1 (the troops' +6.7 ate by «Urquiza marching alone» -10, although
#     his battalions already counted without the allies) and went to Rosas by fortune; -181750 Rosas 9 against 4 scored -2.
#     Now each side's strength on the field is weighed against the other's, 80 for all of it on one side:
#       - Urquiza's: the battalions of Entre Rios and of the provinces in arms with it (the Oriental division is Entre Rios's
#         own), plus the battalions of Brazil's division of the convention still on the board (gg_caseros_in_bn_brz: the allies
#         count by what marches, not by a flag);
#       - Rosas's: the battalions of Buenos Aires and its provinces in arms, less a quarter while its ranks are coming apart
#         (gg_rosas_army_disarray, «Filas que se desgranan», from the crossing of the Parana to the day: Santa Fe's troops
#         rose, Rosario's went over, Pacheco resigned).
#     Twice the other side's strength is decisive on its own against the spirit and the field chosen (2:1 is 27 points; with
#     the quarter, Rosas's 2:1 in battalions is still 16), and like armies with Buenos Aires's ranks thinning lean to Urquiza
#     (26 against 24 battalions: +15). On the twenty measured days with the crossing (their armies, their allied divisions,
#     no battles) this gives Urquiza about two days in three, three in four decided without fortune.
# ES: LOS EJERCITOS COMO ESTAN DECIDEN LA JORNADA, EN PROPORCION. El barrido sobre 832c5cb no peleo ninguna batalla antes de
#     Caseros, asi que la jornada eran las tropas, el animo y las banderas de los aliados, y salia un empate que decidia la
#     suerte aun cuando un lado duplicaba al otro: en 181813 Urquiza 24 batallones contra 12 de Rosas saco +1 (el -10 de
#     «Urquiza solo» se comia el +6,7 de las tropas, aunque sus batallones ya contaban sin los aliados) y fue de Rosas por
#     suerte. Ahora la fuerza de cada lado en el campo se pesa contra la del otro, 80 si es toda de un lado: la de Urquiza,
#     sus batallones y los de las provincias con el mas los de la division brasilena que siguen en el tablero; la de Rosas,
#     los suyos y los de sus provincias, menos un cuarto mientras sus filas se desgranan. El doble del otro decide solo; dos
#     ejercitos parejos con las filas portenas desgranandose se inclinan a Urquiza.
# SOURCE / FUENTE: docs/guerra-grande-argentina/historia-argentina.md, «Caseros» [D] (see the header); es.wikipedia «Batalla de
#     Caseros» (Santa Fe and Rosario troops rise and go over; Pacheco resigns the command). DESIGN / DISENO: the 80 and the
#     quarter are game scale, tuned with the Pact lab (tools/lab_balance/pacto.py) on the measured armies.
# EN/ES: Urquiza's strength on the field / la fuerza de Urquiza en el campo
gg_caseros_day_strength_urquiza = {
	value = global_var:gg_caseros_in_bn_enr
	add = global_var:gg_caseros_in_bn_brz
}

# EN/ES: Rosas's strength on the field: a quarter less while his ranks come apart / la de Rosas: un cuarto menos si sus filas se desgranan
gg_caseros_day_strength_rosas = {
	value = global_var:gg_caseros_in_bn_arg
	if = { limit = { global_var:gg_caseros_in_dis = 1 } multiply = 0.75 }
}

# EN/ES: the troops, one side's strength against the other's / las tropas, la fuerza de un lado contra la del otro
gg_caseros_day_numbers = {
	value = 0
	if = {
		limit = { global_var:gg_caseros_in_bn_all > 0 }
		add = {
			value = gg_caseros_day_strength_urquiza
			subtract = gg_caseros_day_strength_rosas
			divide = global_var:gg_caseros_in_bn_all
			multiply = 80
		}
	}
}

# EN/ES: the spirit of each camp / el animo de cada campo
gg_caseros_day_spirit = {
	value = global_var:gg_caseros_in_ws_enr
	subtract = global_var:gg_caseros_in_ws_arg
	multiply = 5
}

# EN/ES: the reckoning of the day: positive Urquiza, negative Rosas / la cuenta de la jornada: positivo Urquiza, negativo Rosas
gg_caseros_day_score = {
	value = gg_caseros_day_battles
	add = gg_caseros_day_ground
	add = gg_caseros_day_numbers
	add = gg_caseros_day_spirit
}

# EN: 26/9/2026 (Juan, AUD-PACT-ARMY-MELTS) -- THE ARMY URQUIZA'S GOVERNMENT WANTS TO KEEP. In the caseros runs of 26/9 (mod
#     525d532) Entre Rios's battalions went from 22 to 10 in October 1851, 6 in November and 5 in January with no battle, no
#     occupation and no barracks cut by the army model (no «can only support» line in error.log for those months), and the
#     Ejercito Grande raised on 21/11 had no units the next day in spite of its room in the barracks. The engine's AI keeps
#     the number of barracks levels its strategy «wants» (wanted_army_size) and, short of money, disbands what is above it;
#     for a country of one state the Knowledgeable AI playset caps that at four battalions a state (kai_script_values.txt,
#     `max = num_states * 4`; vanilla: one per 250,000 people, ai_script_values.txt), and a newborn Entre Rios paying for a
#     mobilized army of 22 is broke in a few months. This value is what the provinces' own strategies add
#     (gg_ai_strategy_entre_rios / _corrientes, common/ai_strategies/zz_guerra_grande_argentina.txt): while the war of the
#     Pronouncement lasts, the army they have (its barracks levels, AUD-PACT-WANT-LAGS below), less what the default strategy already asks (wanted_army_size is additive
#     across strategies), so the total is exactly the army on the board: the AI neither disbands it nor builds more. When
#     the Ejercito Grande is raised the army grows and the wish grows with it; when the war ends it falls to zero and the
#     provinces demobilize as the Ejercito Grande did after Caseros. Idea from Better Politics Mod's world-revolution
#     strategy (a wanted_army_size in a diplomatic strategy, 2932134122); the numbers are the mod's. Country scope.
# ES: EL EJERCITO QUE EL GOBIERNO DE URQUIZA QUIERE CONSERVAR. En las corridas del 26/9 los batallones de Entre Rios pasaron
#     de 22 a 10 en octubre de 1851, 6 en noviembre y 5 en enero sin batalla, sin ocupacion y sin recorte de cuarteles por el
#     modelo de ejercito, y el Ejercito Grande del 21/11 no tenia unidades al dia siguiente pese a tener lugar. La IA del
#     motor conserva los niveles de cuartel que su estrategia «quiere» y, corta de plata, disuelve lo que sobra; para un pais
#     de un estado el playset (Knowledgeable AI) lo topea en cuatro batallones por estado, y una Entre Rios recien nacida que
#     paga un ejercito movilizado de 22 se funde en meses. Este valor es lo que suman las estrategias de las provincias:
#     mientras dura la guerra del Pronunciamiento, el ejercito que tienen menos lo que ya pide la estrategia por defecto (el
#     valor se suma entre estrategias), asi el total es justo el ejercito en el tablero: la IA ni lo disuelve ni hace mas.
#     Al levantarse el Ejercito Grande crece el ejercito y crece el deseo; al terminar la guerra cae a cero y las provincias
#     desmovilizan, como el Ejercito Grande despues de Caseros. Scope de pais.
# -------------------------------------------------------------------------------------------------
# EN: 26/9/2026 (AUD-PACT-WANT-LAGS) -- BARRACKS LEVELS, NOT army_size. The wanted army is counted in barracks levels
#     (wanted_army_size_script_value: «how many levels of barracks should the AI have»), but army_size counts only the
#     battalions that are already manned. In the six caseros runs on b690118 (traza_20260926-071038/-071040/-074438/-074451/
#     -081848/-081906) the probe showed it: on 27/11/1851, six days after the Ejercito Grande was raised with 18 empty
#     battalions, Entre Rios had 20-26 barracks levels but an army_size of 6-11, so its AI wanted 6-11 and disbanded the
#     rest within the month (BRK_ENR 22 -> 13, 26 -> 14, 20 -> 8; EG 18 -> 10, 13, 8). Before that, from July-September,
#     the same loop turned every cut into a lower wish (20 -> 10 -> 7 -> 3, WANT_ENR = REG_ENR = BRK_ENR after each one):
#     nothing held the wish up. What made the FIRST cut then is not in the probe (army_size was at most 2 under the barracks;
#     debt 23-66 % of the ceiling). With this value the wish equals the barracks by construction, so if BRK_ENR still falls
#     it is not the wish: look at the money (DEBT_ENR, GOLD_ENR). Counting the barracks the province has keeps the wish at the army it raised,
#     empty battalions included, and still neither builds nor disbands on its own account.
# ES: NIVELES DE CUARTEL, NO army_size. El ejercito deseado se cuenta en niveles de cuartel, pero army_size cuenta solo los
#     batallones ya con hombres. En las seis corridas de caseros el 27/11/1851, seis dias despues de levantar el Ejercito
#     Grande con 18 batallones vacios, Entre Rios tenia 20-26 niveles de cuartel y un army_size de 6-11: su IA queria 6-11 y
#     disolvio el resto en el mes. Antes, de julio a septiembre, el mismo lazo convertia cada recorte en un deseo menor
#     (20 -> 10 -> 7 -> 3): nada sostenia el deseo. Que hizo el PRIMER recorte no esta en la sonda (army_size a lo sumo 2
#     debajo de los cuarteles; deuda 23-66 % del techo). Con este valor el deseo es igual a los cuarteles por construccion:
#     si BRK_ENR igual baja, no es el deseo, es la plata (DEBT_ENR, GOLD_ENR). Contar los cuarteles de la provincia sostiene el deseo en el ejercito
#     que levanto, con los batallones vacios, y sigue sin construir ni disolver por su cuenta.
gg_pact_field_army_barracks = {
	value = 0
	every_scope_building = {
		limit = { is_building_type = building_barrack }
		add = this.level
	}
}

# EN: 26/9/2026 (AUD-PACT-ARMY-FLOOR) -- THE WISH NO LONGER FOLLOWS THE CUTS. With the wish equal to the barracks, every cut
#     the engine's AI made for money lowered the wish with it, and nothing brought it back: traza_20260926-213354, Entre Rios
#     BRK 10 (31/5/1851) -> 5 -> 4, the Ejercito Grande 18 (27/11) -> 9 -> 0 (26/1/1852), WANT = BRK after every cut, GOLD 0,
#     debt 2-6 %; Caseros read BN 12 against 6. The AI cuts barracks when its income does not cover its expenses (00_ai.txt
#     MONEY_SPENDING_MAX_RATIO_TO_REMOVE_*), which a province with no gold reserves meets every month, and never while its
#     barracks are under half of what it wants (MONEY_SPENDING_MILITARY_CRITICAL_THRESHOLD = 0.5: «AI will not consider
#     downsizing them further»; the playset does not change it). So, while the war of the Pronouncement lasts, Entre Rios and
#     Corrientes want twice their FLOOR plus one: the barracks the mod mustered or raised for them (gg_pact_army_floor, set at
#     the Pronouncement's muster, +18 for the Ejercito Grande, +3 for the Oriental division: gg_pact_army_floor_add), not the
#     barracks they have today. Under the floor the AI keeps every level; with money it may add one above it, and there the
#     wish is the barracks again (as before), so it never grows further. 27/9/2026 (AUD-PACT-BA-MELTS): Buenos Aires too,
#     with its floor set when it raises Santos Lugares (its barracks plus those ten); the cuts it made were the same leak.
#     Country scope.
# ES: EL DESEO YA NO SIGUE A LOS RECORTES. Con el deseo igual a los cuarteles, cada recorte que la IA hacia por plata bajaba el
#     deseo con el y nada lo devolvia (213354: Entre Rios 10 -> 5 -> 4, el Ejercito Grande 18 -> 9 -> 0, sin oro y con deuda
#     minima; Caseros leyo 12 contra 6). La IA recorta cuarteles cuando el ingreso no cubre el gasto, y nunca mientras tenga
#     menos de la mitad de lo que quiere. Asi que, mientras dura la guerra del Pronunciamiento, Entre Rios y Corrientes quieren
#     el doble de su PISO mas uno: los cuarteles que el mod les reunio o levanto, no los que tienen hoy. Debajo del piso la IA
#     conserva todo; con plata puede sumar uno arriba, y ahi el deseo vuelve a ser los cuarteles, asi que no crece mas.
#     Desde el 27/9, Buenos Aires tambien: su piso se fija al levantar Santos Lugares (sus cuarteles mas esos diez).
gg_pact_field_army_wanted = {
	value = 0
	if = {
		limit = { gg_pact_keeps_field_army = yes }
		add = gg_pact_field_army_barracks
		if = {
			limit = {
				# EN/ES: 27/9/2026 (AUD-PACT-BA-MELTS) -- Buenos Aires too, since Santos Lugares / Buenos Aires tambien
				has_variable = gg_pact_army_floor
				gg_pact_field_army_barracks <= var:gg_pact_army_floor
			}
			subtract = gg_pact_field_army_barracks
			add = var:gg_pact_army_floor
			add = var:gg_pact_army_floor
			add = 1
		}
		subtract = wanted_army_size_script_value
		min = 0
	}
}
