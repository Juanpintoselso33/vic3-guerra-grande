# EN: Thresholds for the war bar. The bar used to be decoration: it moved and nothing followed.
#     These turn a lead of five battles into a real advantage, and ten into a decision.
# ES: Umbrales de la barra de la guerra. La barra era decorativa: se movia y no pasaba nada.
#     Con esto, una ventaja de cinco batallas pesa de verdad, y una de diez decide la guerra.

guerra_grande_blanco_lead = {
	value = global_var:guerra_grande_blanco_score
	subtract = global_var:guerra_grande_colorado_score
}

guerra_grande_colorado_lead = {
	value = global_var:guerra_grande_colorado_score
	subtract = global_var:guerra_grande_blanco_score
}

# EN: T1/T2, the war balance (playtest 2026-09-19). Counting the events, the bar moved 25 times and
#     only twice after 1843: it was frozen for the eight years of the siege, and since the partition
#     halves the lead, the ten points the arbiter asks for were out of reach. The main path of the
#     design -- a peace negotiated on the score -- could not happen, and every game ended by
#     exhaustion or conquest, which was meant to be the emergency exit.
#     The bar reads the war now: the months of closed sea push towards the blancos, the months with
#     the sea open push towards the colorados, four full months to the point and four points at most, so
#     neither can decide the war on its own. The arbiter reads the same number as the bar.
# ES: T1/T2, la balanza de la guerra. Contando los eventos, la barra se movia 25 veces y solo dos
#     despues de 1843: quedaba congelada los ocho anios del sitio, y como la particion parte la
#     ventaja al medio, los diez puntos que pide el arbitro eran inalcanzables. El camino principal
#     del diseanio -- la paz negociada por puntaje -- no podia pasar, y todas las partidas terminaban
#     por agotamiento o conquista, que era la salida de emergencia.
#     Ahora la barra lee la guerra: los meses de mar cerrado empujan hacia los blancos, los meses de
#     mar abierto hacia los colorados, cuatro meses por punto y cuatro puntos como techo, asi ninguno
#     decide la guerra solo. El arbitro lee el mismo numero que la barra.
gg_siege_pressure = {
	value = global_var:gg_siege_months
	divide = 4
	# EN/ES: Codex review 2026-09-19 -- floor, not round: with round the point arrives at two
	#     months, not four / piso, no redondeo: con redondeo el punto llegaba a los dos meses
	floor = yes
	min = 0
	max = 4
}

gg_relief_pressure = {
	value = global_var:gg_relief_months
	divide = 4
	# EN/ES: Codex review 2026-09-19 -- floor, not round: with round the point arrives at two
	#     months, not four / piso, no redondeo: con redondeo el punto llegaba a los dos meses
	floor = yes
	min = 0
	# EN: Codex review, third pass -- the ceiling was 6, and from 1851 the arbiter asks for 5: two
	#     years of open sea opened the peace table by themselves, with the score dead even. The
	#     comment promised the pressure would not decide the war on its own; now it cannot. Four is
	#     below every threshold the arbiter reads, so it always needs something the player did.
	# ES: el techo era 6, y desde 1851 el arbitro pide 5: dos anios de mar abierto abrian la mesa de
	#     paz solos, con el puntaje empatado. El comentario prometia que la presion no decidia la
	#     guerra sola; ahora no puede. Cuatro esta debajo de todos los umbrales del arbitro, asi que
	#     siempre hace falta algo que haya hecho el jugador.
	max = 4
}

gg_war_balance_blanco = {
	value = guerra_grande_blanco_lead
	add = gg_siege_pressure
	subtract = gg_relief_pressure
}

gg_war_balance_colorado = {
	value = guerra_grande_colorado_lead
	add = gg_relief_pressure
	subtract = gg_siege_pressure
}

# EN: T3a. Naval weight of the Defensa's patrons; read only through gg_sea_open (invariant I16).
# ES: T3a. Peso naval de los padrinos de la Defensa; solo se lee a traves de gg_sea_open (I16).
# EN: T10 balance 2026-09-19 (Codex). The sea used to open by itself and stay open: France's subsidy
#     adds 20 in March 1843 and Purvis another 20 in April, which clears the threshold of 60 without
#     the player deciding anything, and from then until Britain leaves in 1849 the siege counter is
#     simply off -- six years with the Cerrito's central mechanic inert. What was missing is the
#     other half of the historical picture: Brown's squadron sitting on the water. A declared
#     blockade backed by real ships now takes 15 off the powers' grip, which is enough to shut the
#     sea while the two European stations are not both in the river, and not enough afterwards. So
#     the Cerrito has to raise the squadron AND keep the powers weak, and the powers taking Brown's
#     ships away (gg_powers.11) ends the pressure with them.
# ES: T10, balance. El mar se abria solo y se quedaba abierto: el subsidio frances suma 20 en marzo
#     de 1843 y Purvis otros 20 en abril, lo que pasa el umbral de 60 sin que el jugador decida nada,
#     y de ahi hasta que Inglaterra se va en 1849 el contador del sitio esta apagado: seis anios con
#     la mecanica central del Cerrito inerte. Faltaba la otra mitad del cuadro historico: la escuadra
#     de Brown sobre el agua. Un bloqueo declarado con barcos de verdad le saca ahora 15 al agarre de
#     las potencias, que alcanza para cerrar el mar mientras las dos estaciones europeas no esten
#     juntas en el rio, y no alcanza despues. El Cerrito tiene que levantar la escuadra Y mantener
#     flojas a las potencias, y si las potencias se llevan los barcos de Brown la presion se va con
#     ellos.
gg_blockade_pressure = {
	value = 0
	if = {
		limit = {
			c:CER ?= { has_variable = gg_brown_squadron_raised }
			c:URU ?= { has_modifier = guerra_grande_river_plate_blockade }
		}
		add = 15
	}
}

gg_sea_power = {
	value = global_var:gg_patron_francia
	add = global_var:gg_patron_britania
	subtract = gg_blockade_pressure
}

# EN: T3a. Total backing of each side (to-be.md section 2); T3b makes it drain war support.
# ES: T3a. Sosten total de cada bando (to-be.md seccion 2); en T3b drena el apoyo a la guerra.
gg_defensa_backing = {
	value = global_var:gg_patron_francia
	add = global_var:gg_patron_britania
	add = global_var:gg_patron_brasil
	# EN/ES: T7 -- Urquiza counts for the side he is on / Urquiza cuenta para el lado donde esta
	if = {
		limit = { has_global_variable = gg_urquiza_flipped }
		add = global_var:gg_patron_urquiza
	}
}

gg_cerrito_backing = {
	value = global_var:gg_patron_rosas
	if = {
		limit = { NOT = { has_global_variable = gg_urquiza_flipped } }
		add = global_var:gg_patron_urquiza
	}
}

# EN: T5, F0-5. How hard Rivera hits at Yucutuja: 2, +1 if the border stayed open to the
#     riograndenses, -1 if Oribe helped the Empire close it, +1 if the northern caudillos were
#     passed over by the government's political chiefs, -1 if they were left in charge.
# ES: T5, F0-5. Cuanto pega Rivera en Yucutuja: 2, +1 si la frontera quedo abierta a los
#     riograndenses, -1 si Oribe ayudo al Imperio a cerrarla, +1 si los caudillos del norte fueron
#     desplazados por jefes politicos, -1 si se los dejo al frente.
gg_rivera_1837_strength = {
	value = 2
	if = {
		limit = { has_global_variable = gg_farrapos_closed }
		add = -1
	}
	else = {
		add = 1
	}
	if = {
		limit = { has_global_variable = gg_depts_state_chiefs }
		add = 1
	}
	else_if = {
		limit = { has_global_variable = gg_depts_local_caudillos }
		add = -1
	}
	# EN/ES: balance 2026-09-17 -- capped at 1..3 (was 0..4); min/max run in order, so last / acotado a 1..3 (era 0..4); van al final
	min = 1
	max = 3
}

# EN: balance 2026-09-17. What the split takes off the lead: half of it, rounded up, so half of
#     the lead (rounded down) is left. / ES: lo que la particion le saca a la ventaja: la mitad
#     redondeada para arriba, asi queda la mitad redondeada para abajo.
gg_split_trim = {
	value = guerra_grande_blanco_lead
	if = {
		limit = { guerra_grande_blanco_lead < 0 }
		multiply = -1
	}
	divide = 2
	round = yes
}

	max = 10
}

# EN: T2, the arbiter's tie-break (playtest 2026-09-19). Positive means the Defensa is the more
#     exhausted of the two; negative, the Cerrito. / ES: positivo, la Defensa esta mas agotada que
#     el Cerrito; negativo, al reves.
gg_exhaustion_gap = {
	value = global_var:gg_defensa_exhausted
	subtract = global_var:gg_cerrito_exhausted
}

# EN: THE DELEGATION BAR. Thirteen provinces delegate; twelve internal points make one of them. The
#     bar divides and shows the result WITHOUT flooring: 8.4 delegations is exactly what we want to
#     see, because flooring would hide eleven months of wear and make the bar jump once a year --
#     which would tell the player that holding Oribe costs nothing until suddenly it costs a
#     province. It is the opposite of what the mechanic is about.
# ES: LA BARRA DE LA DELEGACION. Trece provincias delegan; doce puntos internos hacen una. La barra
#     divide y muestra el resultado SIN redondear para abajo: 8,4 delegaciones es exactamente lo que
#     queremos ver, porque redondear escondería once meses de desgaste y haría que la barra saltara
#     una vez por año -- le diría al jugador que sostener a Oribe no cuesta nada hasta que de golpe
#     cuesta una provincia. Es lo contrario de lo que trata la mecánica.
gg_delegation_bar_value = {
	value = global_var:gg_delegation_points
	divide = 12
	min = 0
	max = 13
}

# EN: what is left of the Ejercito Unido de Vanguardia when it crosses, read from how the interior
#     campaign ended. Five battalions if Rosas had the interior quiet, three if it cost him.
# ES: lo que queda del Ejercito Unido de Vanguardia cuando cruza, leido de como termino la campania
#     del interior. Cinco batallones si Rosas tuvo el interior quieto, tres si le costo.
gg_vanguardia_line = {
	value = 3
	if = {
		limit = { global_var:gg_interior_outcome = 2 }
		subtract = 1
	}
	# EN: AND ONE FEWER IF ROSAS NEVER CALLED HIM PRESIDENT. On the day Oribe landed in Buenos Aires
	#     the player chose between receiving him as the lawful president of the Oriental Republic --
	#     which is what Rosas did, and what cost him abroad for the rest of his life -- and taking him
	#     in as a soldier and saying nothing. Until 20/9/2026 that choice wrote a mark that NOBODY
	#     READ: the two roads did exactly the same thing. An army lent to a foreign president in exile
	#     is a different thing from an army lent to a general on the payroll, and the difference shows
	#     up here, where the Vanguardia is counted out.
	# ES: Y UNO MENOS SI ROSAS NUNCA LO LLAMO PRESIDENTE. El dia que Oribe desembarco en Buenos Aires
	#     el jugador eligio entre recibirlo como presidente legal de la Republica Oriental --que es lo
	#     que hizo Rosas, y lo que le costo afuera el resto de su vida-- y recibirlo de militar sin
	#     decir nada de la presidencia. Hasta el 20/9/2026 esa eleccion escribia una marca que NO LEIA
	#     NADIE: los dos caminos hacian exactamente lo mismo. Un ejercito prestado a un presidente
	#     extranjero en el exilio no es lo mismo que un ejercito prestado a un general a sueldo, y la
	#     diferencia se ve aca, cuando se cuenta la Vanguardia.
	if = {
		limit = { NOT = { has_global_variable = gg_oribe_recognised } }
		subtract = 1
	}
	if = {
		limit = { global_var:gg_vanguardia_cruce = 2 }
		subtract = 1
	}
	# EN/ES: y un piso de uno: dos recortes sobre dos caballerias dan cero, y un contingente de cero
	#     unidades no es un contingente / and a floor of one: two cuts on two would give zero
	min = 1
}
