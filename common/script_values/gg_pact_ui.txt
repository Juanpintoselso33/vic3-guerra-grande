# EN: 23/9/2026 (Juan: the Banda Oriental counts for the Pact when it is in it) -- THE PACT'S COUNT: the thirteen
#     provinces' counter (gg_delegating_provinces, which the other systems read on their own terms) plus the
#     Oriental while it is a province of the Pact (it always delegates). 14 with it, 13 without. The band shows it
#     and the Pact's closing (je_gg_delegation complete) and the same line in Rosas's backing of Oribe
#     (gg_int_arg_* <= 6) read it, so what the player sees is what closes the Pact.
# ES: LA CUENTA DEL PACTO: las trece mas la Oriental mientras sea provincia del Pacto (siempre delega); 14 con
#     ella, 13 sin ella. La muestra la franja y la leen el cierre del Pacto y la misma linea del respaldo a Oribe.
gg_pact_delegating = {
	value = 0
	if = { limit = { has_global_variable = gg_delegating_provinces } value = global_var:gg_delegating_provinces }
	if = { limit = { has_global_variable = gg_oriental_in_pact } add = 1 }
}
gg_ui_pact_delegating_shown = {
	value = gg_pact_delegating
}
