# EN: The oriental states belong to a strategic region (standalone, 19 September 2026). Vanilla puts
#     STATE_URUGUAY inside region_brazil; this mod replaces that state with five, so the region has

#     This is what REPLACE: is for: the region keeps existing, only its contents change, so the file
#     does not shadow vanilla's and any other mod's regions survive. The list is vanilla's, minus
#     STATE_URUGUAY, plus the five.
# ES: los estados orientales tienen que pertenecer a una region estrategica. Vanilla mete

#     este mismo dia.
#     Para esto sirve REPLACE:: la region sigue existiendo y solo cambia su contenido, asi que el
#     archivo no pisa el de vanilla y las regiones de cualquier otro mod sobreviven. La lista es la
#     de vanilla, menos STATE_URUGUAY, mas los cinco.
# -------------------------------------------------------------------------------------------------
